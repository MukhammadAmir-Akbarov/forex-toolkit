    Телеграм Бот созлаш бўйича қўлланма — сигналларни Телеграмда олинг¶

    Бу нима беради¶

    Ҳар соатда (ёки жадвал бўйича) скрипт: 1. ЭУР/УСД шамларини юклаб олади (йфинансе) 2. Бизнинг стратегиямизни қўллайди 3. Янги сигнал бўлса — Телеграмда хабар юборади

    Хабар намунаси: 

    🚨 Forex Signal

Juft: EURUSD
Yo'nalish: 🟢 LONG
Vaqt: 2026-05-20 14:00

Kirish: 1.08520
Stop Loss: 1.08270 (25 pip)
Take Profit: 1.09020 (R:R 1:2.0)

Sabab: BullEng

⚠️ Bu savdo tavsiyasi emas. Kirishdan oldin chek-listni tekshiring.

    1-қадам: Телеграм-бот яратиш¶

    1. Телеграмни очинг, @БотФатҳер контактини топинг
    2. /newbot ёзинг
    3. БотФатҳер бот номини сўрайди — масалан: «Форех Сигналс Мй Бот»
    4. Кейин усернаме сўрайди — bot билан тугаши керак, масалан: forex_signals_amir_bot
    5. Токен билан хабар оласиз: 
      123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
      Бу сизнинг TELEGRAM_BOT_TOKEN. Ҳеч кимга кўрсатманг.

    2-қадам: чат_ид олиш¶

    Бу сизнинг шахсий ИДъингиз — бот кимга ёзишини билиши учун керак.

    1-усул (осонроқ)¶

    1. Телеграмда @усеринфобот ни топинг
    2. /start ёзинг
    3. Сизнинг ИД билан хабар келади, масалан: 
      👤 Id: 123456789
First name: Amir

    Бу сизнинг TELEGRAM_CHAT_ID.

    2-усул (АПИ орқали)¶

    1. Яратилган ботга Телеграмда бирор нарса ёзинг (исталган хабар, масалан «салом»)
    2. Браузерда очинг: 
      https://api.telegram.org/bot<TWOI_TOKEN>/getUpdates
      (<TWOI_TOKEN> ўрнига 1-қадамдаги токенни киритинг)
    3. ЖСОН-жавобда "chat":{"id":123456789,...} ни топинг — бу сизнинг чат_ид

    3-қадам: Муҳит ўзгарувчиларини созлаш¶

    Лойиҳа терминалини очинг:

    cd /Users/mukhammadamir/Sites/WORK/trading

# O'z qiymatlaringizni kiriting
export TELEGRAM_BOT_TOKEN="123456789:ABCdef..."
export TELEGRAM_CHAT_ID="123456789"

    Ўзгарувчилар сессиялар орасида сақланиши учун — ~/.zshrc га қўшинг:

    echo 'export TELEGRAM_BOT_TOKEN="123456789:ABCdef..."' >> ~/.zshrc
echo 'export TELEGRAM_CHAT_ID="123456789"' >> ~/.zshrc
source ~/.zshrc

    4-қадам: Синов ишга тушириш¶

    Аввал — дрй-рун (Телеграмга юбормасдан):

    .venv/bin/python advanced/telegram_alerts.py --symbol EURUSD --dry-run

    Терминалда қайси сигналлар юборилиши мумкинлиги кўрсатилади.

    Натижа яхши кўринса — юбориш билан ишга тушириш:

    .venv/bin/python advanced/telegram_alerts.py --symbol EURUSD

    Телеграмни очинг → сигнал келиши керак (агар сўнгги соатларда мавжуд бўлса).

    5-қадам: Ҳар соатда автоматик ишга тушириш¶

    А-вариант: срон (масОС / Линух)¶

    crontab -e

    Қаторни қўшинг: 

    0 * * * * cd /Users/mukhammadamir/Sites/WORK/trading && /Users/mukhammadamir/Sites/WORK/trading/.venv/bin/python advanced/telegram_alerts.py >> /tmp/telegram_alerts.log 2>&1

    Бу қатор скриптни ҳар соат бошида ишга туширади. Логлар /tmp/telegram_alerts.log га сақланади.

    ⚠️ Сронда муҳит ўзгарувчилари мавжуд эмас! Уларни буйруққа қўшинг: 

    0 * * * * cd /Users/mukhammadamir/Sites/WORK/trading && TELEGRAM_BOT_TOKEN="123..." TELEGRAM_CHAT_ID="123..." /Users/mukhammadamir/Sites/WORK/trading/.venv/bin/python advanced/telegram_alerts.py >> /tmp/telegram_alerts.log 2>&1

    Ёки .env файлидан фойдаланинг (қуйида кўринг).

    Б-вариант: лаунчд (масОС, тўғрироқ усул)¶

    ~/Library/LaunchAgents/com.amir.forex-alerts.plist файлини яратинг:

    <?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
"http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>com.amir.forex-alerts</string>
  <key>ProgramArguments</key>
  <array>
    <string>/Users/mukhammadamir/Sites/WORK/trading/.venv/bin/python</string>
    <string>/Users/mukhammadamir/Sites/WORK/trading/advanced/telegram_alerts.py</string>
  </array>
  <key>EnvironmentVariables</key>
  <dict>
    <key>TELEGRAM_BOT_TOKEN</key>
    <string>123456789:ABCdef...</string>
    <key>TELEGRAM_CHAT_ID</key>
    <string>123456789</string>
  </dict>
  <key>StartCalendarInterval</key>
  <dict>
    <key>Minute</key>
    <integer>5</integer>
  </dict>
  <key>StandardOutPath</key>
  <string>/tmp/telegram_alerts.log</string>
  <key>StandardErrorPath</key>
  <string>/tmp/telegram_alerts.error.log</string>
</dict>
</plist>

    Ишга туширинг: 

    launchctl load ~/Library/LaunchAgents/com.amir.forex-alerts.plist

    Ҳар соатда 5-дақиқада ишга тушади.

    Тўхтатиш: 

    launchctl unload ~/Library/LaunchAgents/com.amir.forex-alerts.plist

    В-вариант: булутли сервер (доимий ишлаш учун)¶

    Қуйидагиларда жойлаштириш мумкин: - Ҳероку (бепул тариф — 550 соат/ой) - ПйтҳонАнйвҳере (бепул, оддий срон созлаш) - Рендер (бепул тариф) - ВПС-даги контейнер (агар мавжуд бўлса)

    Ҳозирча маҳаллий ишга туширишни ўзлаштириб олинг — чуқурроқ кирмаймиз.

    6-қадам: Токенни хавфсиз сақлаш¶

    ⚠️ Токенни ҳеч қачон Гитъга пушманг!

    Илдизда .env файлини яратинг:

    TELEGRAM_BOT_TOKEN=123456789:ABCdef...
TELEGRAM_CHAT_ID=123456789

    .env аллақачон .gitignore да мавжуд.

    пйтҳон-дотенв орқали юкланг:

    .venv/bin/pip install python-dotenv

    telegram_alerts.py бошига (қўшиш мумкин): 

    from dotenv import load_dotenv
load_dotenv()

    7-қадам: Функсионалликни кенгайтириш¶

    Ботни кенгайтириш мумкин:

    Бир нечта жуфтлар¶

    for pair in EURUSD GBPUSD USDJPY; do
  .venv/bin/python advanced/telegram_alerts.py --symbol $pair
done

    Бот буйруқлари (икки томонлама алоқа)¶

    Ботга ёзиш имконияти: - /status → жорий очиқ сигнал - /stats → сўнгги сигналлар статистикаси - /disable EURUSD → жуфтни ўчириш

    Бу python-telegram-bot кутубхонасини талаб қилади: 

    .venv/bin/pip install python-telegram-bot

    Дўстлар билан сигнал гуруҳи¶

    1. Телеграмда гуруҳ яратинг
    2. Ботингизни гуруҳга қўшинг
    3. Ботни админ қилинг (@БотФатҳер орқали)
    4. Гуруҳ чат_ид ни олинг (/getUpdates орқали, ЖСОН да манфий ИД бўлади)
    5. Бу ИД ни TELEGRAM_CHAT_ID сифатида ишлатинг

    8-қадам: Сигналлар билан нима қилиш керак¶

    Бот сигнал юборди — бу савдо қилиш буйруғи эмас. Бу билдиришнома — скриптимиз сетап топганини англатади.

    Савдони очишдан олдин: 1. ✅ МТ5 ни очинг → сетап ҳақиқатан борлигини текширинг (бот хато қилиши мумкин) 2. ✅ Чоп этиладиган чек-лист бўйича ўтинг 3. ✅ поситион_салсулатор.пй ни ишга туширинг 4. ✅ Очишдан ОЛДИН режалаштирилган параметрларни журналга ёзинг 5. ✅ СЛ ва ТП билан савдони очинг

    Ҳеч қачон сигналдан дарҳол текширувсиз савдо очинг.

    Муаммоларни бартараф этиш¶

    Бот /старт га жавоб бермаяпти¶

    • Эҳтимол, токен нотўғри
    • Бот блокланмаганлигини текширинг

    Хабарлар келмаяпти¶

    • чат_ид ни текширинг — бу сизнинг ИДъингиз бўлиши керак, усернаме эмас
    • --dry-run билан ишга туширинг — сигналлар умуман генерация қилинаётганлигини кўрасиз

    йфинансе ишламай қолди¶

    • йфинансе баъзан тез-тез сўровларни блоклайди → 10 дақиқа кутинг
    • Эҳтимол, интернет йўқ

    Сигналлар «эскирган» кўринади¶

    • йфинансе котировкаларни 15-30 дақиқа кечикиш билан беради
    • Реал вақтда савдо учун брокер АПИ ёки пуллик маълумотлар тасмаси керак

    Якуний эслатма¶

    🚨 Телеграм-бот — бу фақат билдиришномалар. Ҳеч қандай автоматик ордерлар йўқ. Ҳар бир савдо бўйича қарорни ўзингиз қабул қиласиз. Бот сетапларни аниқлаш жараёнини тезлаштиради, лекин сизнинг таҳлил ва интизомингизни алмаштирмайди.
