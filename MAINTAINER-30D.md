# 📅 MAINTAINER-30D — 30-дневный план для тебя как maintainer'а

> Это **личный план** maintainer'а на месяц после официального запуска проекта.
> **Не про код**, а про дисциплину и поведение.
>
> Цель: выйти из режима «строитель» и войти в режим «оператор + маркетер».
> Project уже готов технически. Дальше — найти пользователей и слушать их.

---

## 🎯 Принципы месяца

1. **0 новых фич** без явного запроса от реального пользователя
2. **Каждый день** — 30 минут на проект (маркетинг, ответы, журнал)
3. **Замер метрик** — каждое воскресенье
4. **Свой journal** — обязателен, ты используешь свои же инструменты

---

## Неделя 1 — Запуск

### День 1-2: Reddit r/Forex
- Открыть [LAUNCH.md](LAUNCH.md), скопировать пост для r/Forex
- **Адаптировать**: убери шаблонность, добавь личное (почему ты это делал)
- Опубликовать во вторник 8-10 AM UTC
- Прочитать комментарии через 2 часа, 6 часов, 24 часа
- **Отвечать на каждый** в течение 1 часа

### День 3-4: r/algotrading + Узбекский Telegram
- r/algotrading с техническим углом (Risk Guardian, бэктестер)
- Найти 1-2 узбекских Telegram-канала по трейдингу
- **Не спамь** — напиши лично админу, спроси можно ли поделиться

### День 5: Открыть демо-счёт
- Выбрать брокера из [сравнения](https://mukhammadamir-akbarov.github.io/forex-toolkit/extras/brokers-comparison/)
- Открыть demo с виртуальными $1000
- Подключить MT5 / web-терминал
- **Не торгуй** в этот день — просто настройка

### День 6-7: Метрики
- Зайти в [Insights → Traffic](https://github.com/MukhammadAmir-Akbarov/forex-toolkit/graphs/traffic)
- Замерить:
  - Уникальных visitors
  - Clones
  - Stars (через [stargazers](https://github.com/MukhammadAmir-Akbarov/forex-toolkit/stargazers))
  - Release downloads
- Записать в текстовый файл `week1-metrics.txt` (не пуш!)

## Неделя 2 — Использовать самому

### Понедельник — Среда: 5 сделок на демо
- Каждая через [position-calculator](https://mukhammadamir-akbarov.github.io/forex-toolkit/tools/position-calculator/)
- Стратегия: **EMA50 pullback** (из своего же учебника)
- Каждую — в `journal_cli.py add`:
  ```bash
  .venv/bin/python tools/journal_cli.py add \
      --pair EURUSD --dir long \
      --entry 1.0852 --sl 1.0827 --tp 1.0902 \
      --lot 0.02 --risk 5 --rules yes
  ```

### Четверг — Пятница: ещё 5 сделок
- **Замечай неудобства** в своих же инструментах
- Каждое неудобство → `~/notes-friction.md` (не для пуша)

### Суббота: ретроспектива
- Запустить `tools/journal_analyzer.py` на своём журнале
- **Что показало?** Win rate, expectancy, паттерны
- Полностью прочитать → запишите 3 инсайта о себе

### Воскресенье: формулировка
- Превратить 3 friction-точки в 3 GitHub Issues **самому себе**:
  - Title: "[UX] описание проблемы"
  - Body: что неудобно + что хотелось бы
- **Не закрывай их сам сразу** — пусть лежат как идеи

## Неделя 3 — Ответить на feedback

### Понедельник: проверка [Discussions](https://github.com/MukhammadAmir-Akbarov/forex-toolkit/discussions)
- Если есть комментарии → **отвечай в течение 24 часов**
- Если 0 комментариев → это **сигнал**:
  - Reddit/Telegram пост не сработал
  - Нужно сменить платформу или подачу
  - **Не паникуй** — open source медленный, это норма первый месяц

### Вторник: повторный лонч
- Опубликовать в **другую платформу** (Show HN или Dev.to статья)
- Использовать другой ракурс: «вот как сделал», а не «вот фичи»

### Среда — Пятница: продолжай торговать
- Ещё 5 сделок на демо
- Журнал каждой

### Суббота: контент
- Написать **1 пост в Discussions** от своего имени:
  - «📊 Мой первый месяц с проектом: что узнал»
  - Покажи свой journal_analyzer вывод (анонимизированный)
  - Покажи 1 баг, который сам нашёл

### Воскресенье: метрики недели 3
- Сравнить с неделей 1
- Записать в `week3-metrics.txt`

## Неделя 4 — Ретроспектива

### Понедельник — Среда: финальные сделки
- Ещё 5 сделок на демо (всего за месяц должно быть **15+** на демо)

### Четверг: глубокий анализ
- `journal_analyzer.py` на всём журнале
- Заполнить [mistakes-log.md](https://github.com/MukhammadAmir-Akbarov/forex-toolkit/blob/main/journal/mistakes-log.md) для себя:
  - Какие 3 ошибки повторял?
  - Какие правила Trading Plan нарушил?

### Пятница: оценка проекта
- Прочитать твои собственные 3 Issues с недели 2
- Что **реально** мешает? Что было fancy идеей?
- Закрой 1-2 как «won't fix» если не нужны

### Суббота: решение
- На основе данных за месяц **выбери одно направление** на следующий месяц:

| Если у тебя… | Делай |
|---|---|
| ≥ 10 stars, ≥ 2 issues от юзеров | Углубляй: v0.2.0 с user-driven фичами |
| 0 stars, 0 visitors | Меняй подачу: новые тексты в LAUNCH.md, другие платформы |
| Активные Discussions | Стань community-фасилитатором: pinned weekly digest |
| Свой journal показал слабую дисциплину | Возьми ещё месяц на тренировку, не лезь в реал |

### Воскресенье: коммит
- Напиши краткий **personal retro** в `~/private-retro.md`
- Не для GitHub. Для себя.

**Красный сценарий**: ≤ 2 метрик достигнуто — проблема в дистрибуции / маркете, не в коде. Не добавляй фичи, меняй подачу.
