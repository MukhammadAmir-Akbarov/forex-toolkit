    Trading Journal — как пользоваться¶

    Два формата шаблона:

    • trading-journal-template.md — для ведения в Markdown (Obsidian, Notion, VSCode). Удобно для подробных ревью.
    • trading-journal-template.csv — для импорта в Google Sheets / Excel. Удобно для статистики и графиков.

    Как начать¶

    Вариант 1: Google Sheets (рекомендую для начала)¶

    1. Открой sheets.google.com
    2. Файл → Импорт → Загрузить → выбери trading-journal-template.csv
    3. Тип импорта: «Заменить лист»
    4. Создай заголовки-формулы во второй вкладке для аналитики:
    B2: =COUNTIF(Trades!U:U,"Win")                 // кол-во побед
B3: =COUNTIF(Trades!U:U,"Loss")                // кол-во убытков
B4: =B2/(B2+B3)                                // win rate
B5: =SUMIF(Trades!U:U,"Win",Trades!S:S)        // сумма прибылей
B6: =-SUMIF(Trades!U:U,"Loss",Trades!S:S)      // сумма убытков (модуль)
B7: =B5/B6                                     // profit factor
B8: =B5+SUMIF(Trades!U:U,"Loss",Trades!S:S)    // чистый P&L

    Вариант 2: Markdown в Obsidian / VSCode¶

    1. Скопируй trading-journal-template.md в свою папку
    2. После каждой сделки: копируй блок «Шаблон новой сделки» и заполняй
    3. Один файл на месяц (2026-05.md, 2026-06.md…)
    4. В конце недели — добавляй еженедельный отчёт

    Вариант 3: Notion¶

    Создай базу с такими полями:

    Поле Тип
    ID Number
    Дата Date
    Пара Select
    Направление Select (Long / Short)
    Сетап Text
    Вход / SL / TP Number
    Размер лота Number
    Риск $ Number
    Результат $ Number
    R-итог Number
    Исход Select (Win / Loss / BE)
    Правила? Checkbox
    Эмоции Multi-select
    Ошибки Text
    Вывод Text
    Скриншот Files

    Какие поля абсолютно обязательны¶

    Минимум для каждой сделки:

    1. Дата + время — для разбора по времени суток
    2. Пара + направление
    3. Цена входа / SL / TP / лот
    4. Результат (пипсы и $ обязательно, R желательно)
    5. Следовал правилам? (да/нет) — самый важный поведенческий чекбокс
    6. 1–2 предложения вывода

    Подробные поля (эмоции, скриншот, длинное ревью) — желательны, но не блокеры. Начни с минимума, добавляй по мере привычки.

    Что считать раз в неделю¶

    Открой Google Sheets, посчитай:

    Метрика Что хорошо
    Win rate ≥ 40% (для R:R 1:2)
    Profit Factor ≥ 1.5
    Avg Win / Avg Loss ≥ 2.0
    Чистый P&L > 0
    Max просадка за неделю < 6% депозита
    % сделок по правилам ≥ 95%

    Если % по правилам < 95 — проблема в дисциплине, не в стратегии. Чини это в первую очередь.

    Что искать в анализе¶

    После 30+ сделок открой журнал и задай вопросы:

    • В какое время суток ты прибыльнее? (например, утренние сделки = плюс, вечерние = минус)
    • В какой день недели хуже? (например, пятница = плюс, понедельник = минус)
    • На каких парах ты лучше?
    • Сетапы по правилам vs «интуитивные» — разница в результате?
    • В каком эмоциональном состоянии ты теряешь деньги?

    Эти выводы важнее любых индикаторов.
