# Changelog

Все заметные изменения проекта. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Исправлено
- **Калькулятор позиции больше не занижает риск молча.** `PositionResult`
  получил флаг `risk_exceeds_plan`: когда лот поднимается до минимального 0.01 и
  фактический риск превышает плановый, флаг = `True` (CLI/виджет предупреждают).
- **Дублирование формулы устранено.** `forex_toolkit/position_calculator.py`
  использует `fx_math.calc_lots`, а не свою копию `math.floor(...)` (см. CLAUDE.md).
- **`broker_api` стал безопаснее.** `BinanceBroker.place_order` больше не теряет
  стоп молча — бросает `NotImplementedError`; `MT5Broker` блокирует авто-торговлю
  на реальном счёте (разрешена только демо/`FX_ALLOW_LIVE=1`).
- `macd` и `is_doji` экспортируются из `forex_toolkit` (`__all__`).
- Кириллические якоря оглавлений (`toc.slugify: uslugify`); `mkdocs build
  --strict` проходит и включён в CI.
- **CLI работает из установленного wheel.** `forex_toolkit/cli.py` больше не
  зависит от запуска из репозитория: скрипты инструментов вшиваются в wheel
  (`forex_toolkit/_tools/`) и исполняются через `runpy`. Раньше после
  `pip install forex-toolkit` все 8 команд падали.
- `forex-journal` пишет журнал в `journal/` рабочей директории, а не в
  `site-packages` (учитывает переменную `FOREX_JOURNAL`).

### Добавлено
- Модуль `forex_toolkit.fx_math` — единый источник правды для формул pip-value
  и calc_lots (убрано дублирование между калькуляторами).
- Тесты математики пакета (`tests/test_indicators.py`): индикаторы, свечные
  паттерны, калькулятор позиции. Всего тестов — 130, покрытие пакета ~98%.
- Веб-квиз «готов ли ты к реалу?» (`_mkdocs/tools/quiz.md`) — 18 вопросов с
  пояснениями и сохранением рекорда в браузере.
- Гейт тестов в `release.yml` (сломанный тег больше не публикует wheel/PDF).
- CI-джобы: `lint` (ruff + mypy), `coverage` (порог покрытия), `package`
  (установка wheel и запуск всех CLI-команд), `docs` (сборка + страж дублей).
- Браузерные виджеты (без Python): тренажёр карточек, «Риск разорения»
  (Монте-Карло), предторговый чек-лист, трекер прогресса, UZS-калькулятор вывода.
- `.env.example`, `tools/check_docs_sync.py`, авто-релизы (`release.yml`),
  еженедельная проверка здоровья (`weekly-health.yml`), `CLAUDE.md`.

### Изменено
- Покрытие меряется только по пакету `forex_toolkit` (а не по скриптам
  `tools/bot/strategies`); порог гейта поднят с 15% до 90% (факт ~98%).
- В практических главах усилены предупреждения о риске: цитата про «полное
  плечо» на золоте обёрнута в `danger`, таблица лотов привязана к правилу ≤1%,
  исправлена 10-кратная неоднозначность в стоимости пипса золота.
- `_mkdocs/` — единственный источник правды для контента; удалены 37 корневых
  дублей `.md`, сборщики PDF/DOCX читают из `_mkdocs/`.
- Секреты MetaTrader 5 берутся из переменных окружения, а не из аргументов CLI.
- Границы версий numpy/pandas приведены к протестированным релизам.
