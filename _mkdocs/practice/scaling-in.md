# 📈 Доливка (Scaling-in) — когда добавляться к позиции

!!! abstract "Из практики (229 упоминаний в архиве)"
    «Доливка» (Dolivka) — добавление к **уже прибыльной** позиции для увеличения профита.

    Важно: это **не усреднение** убыточной позиции (тот метод убивает депозиты).

---

## 🎯 Что такое правильная доливка

### ❌ НЕПРАВИЛЬНО (усреднение убытка)

```
BUY 0.01 @ 1.0850   ← открыли
Цена идёт ВНИЗ к 1.0820 (минус 30 пипсов)
BUY 0.02 @ 1.0820   ← добавились "чтобы средняя стала лучше"
Цена идёт к 1.0790 (минус ещё 30)
BUY 0.04 @ 1.0790   ← снова добавились
...

Результат: депозит уничтожен.
Это казино, не торговля.
```

### ✅ ПРАВИЛЬНО (доливка к прибыли)

```
BUY 0.01 @ 1.0850   ← открыли, риск 1% депозита
Цена идёт ВВЕРХ к 1.0875 (+25 пипсов прибыли)
SL сначала переносим в БУ (см. "Сейф")
Теперь риск = 0
BUY 0.01 @ 1.0875   ← доливка №1 на пробое HH

Цена доходит до 1.0900
SL обеих позиций двигаем выше входа доливки
BUY 0.01 @ 1.0900   ← доливка №2

Когда тренд останавливается — закрываем полностью.
```

---

## 📐 Правила доливки

### Правило 1: Сначала «Сейф», потом доливка

**Не добавляйся к позиции, у которой ещё есть риск убытка.**

Сначала:
1. Перенеси SL базовой позиции в БУ
2. Дождись подтверждения движения (новый HH / LL)
3. Только тогда — доливка

### Правило 2: Лот доливки = лот первой позиции (или меньше)

```
Базовая: 0.01
Доливка №1: 0.01 (или 0.005)
Доливка №2: 0.005 (ещё меньше)
```

**Никогда не увеличивай лот на доливке!** «Я уверен, поставлю 0.05» = большая ошибка.

### Правило 3: Доливка только на пробое уровня

Не «по интуиции», а **по структуре**:
- Для BUY: пробой предыдущего HH (Higher High)
- Для SELL: пробой предыдущего LL (Lower Low)

### Правило 4: Не больше 2-3 доливок

```
Базовая позиция → доливка 1 → доливка 2 → СТОП
```

Если ты делаешь 4-5 доливок на одной волне — это **гордыня и жадность**, не стратегия.

### Правило 5: На последней доливке SL подтягивается под предыдущую

```
Базовая @ 1.0850 → SL 1.0850 (БУ)
Доливка 1 @ 1.0875 → SL обеих 1.0865 (защита 15 пипсов на базовой)
Доливка 2 @ 1.0900 → SL всех 1.0885 (защита 25 пипсов профита)
```

## 🎯 Когда доливаться, а когда НЕТ

### ✅ ЕСТЬ смысл доливаться:

- Сильный трендовый день (например, после FOMC)
- Пробой ключевого уровня с подтверждением
- В свинге (H4+) после консолидации
- Базовая позиция уже в БУ
- На рынке высокая волатильность (золото, EUR/USD в новость)

### ❌ НЕТ смысла доливаться:

- На флэте, в боковике
- На пятничном вечере (закрытие позиции скоро)
- Если базовая позиция ещё не в БУ
- За 1-2 часа до красной новости
- Если ты уже на эйфории и «всё пойму»

## 🔢 Математика доливки

### Без доливки:

```
1 позиция, лот 0.01
Движение: +100 пипсов
Прибыль: $10 (для 1 пипса = $0.10)
```

### С правильной доливкой:

```
Базовая 0.01 @ 1.0850 → +100 пипсов = $10
Доливка 1 (0.01) @ 1.0875 → +75 пипсов = $7.50
Доливка 2 (0.005) @ 1.0900 → +50 пипсов = $2.50

Итого: $20 на том же риске (потому что базовая в БУ)
```

**Доливка удваивает доход при правильной защите.**

### С неправильной доливкой (усреднение):

```
Базовая 0.01 @ 1.0850 → -30 пипсов = -$3
"Усредняю" 0.02 @ 1.0820 → -30 пипсов = -$6
"Ещё усредняю" 0.04 @ 1.0790 → -30 пипсов = -$12
Цена идёт ещё на -50 → СТОП по всем = -$50+

ИТОГО: -$71 на сделке, которая должна была быть риском $3.
```

## ⚠️ Главные ошибки доливки

### ❌ «Я уверен, поставлю огромную доливку»

Это эмоциональное решение. Лот доливки **строго ≤** лоту базовой.

### ❌ Доливка без переноса SL

Самая опасная ошибка: добавился, не подтянул SL, рынок развернулся — теряешь сразу две позиции.

### ❌ Доливка в обратную сторону «чтобы хеджировать»

Это создаёт хаос в голове. Если хочешь хеджа — закрой позицию и открой новую в обратную сторону.

### ❌ Доливка в третий-четвёртый раз без анализа

После 2 доливок **обязательно** оценить:
- Не перегружен ли депозит?
- Не на верхушке ли движения мы?
- Что говорит технический анализ?

## 📊 Доливка vs Pyramiding vs Martingale

| Метод | Что это | Безопасно? |
|---|---|---|
| **Доливка (правильная)** | Добавление к прибыли при защищённой базе | ✅ Да |
| **Pyramiding** | То же, что доливка, в трейдерской литературе | ✅ Да |
| **Martingale** | Удвоение лота после убытка | ❌ Гарантированная смерть депозита |
| **Усреднение** | Добавление к убытку | ❌ Уничтожает депозиты |
| **Hedge-grid** | Сетка ордеров в обе стороны | ⚠️ Очень рискованно для новичка |

**Для новичка: ТОЛЬКО доливка к прибыли с защищённой базой. Точка.**

---

## ✅ Чек-лист правильной доливки

Перед каждой доливкой:

- [ ] Базовая позиция уже в БУ (SL = вход)
- [ ] Лот доливки ≤ лот базовой
- [ ] Это доливка по пробою уровня (HH / LL), а не «по чуйке»
- [ ] Я не на 3+ доливке (максимум 2)
- [ ] До красной новости больше 1 часа
- [ ] Я после доливки немедленно подтягиваю SL обеих позиций
- [ ] Суммарный риск всё ещё в пределах 2-3% депозита

## 💬 Цитата практика

!!! quote
    *«ТП1 +30 пипс ✅✅ сейф киламиз ... доливка @ 1965.»*

    **Перевод:** «Take Profit 1 достигнут +30 пипсов ✅✅ делаем сейф ... доливка на 1965.»

Порядок: **профит → сейф → доливка**. Не наоборот.
