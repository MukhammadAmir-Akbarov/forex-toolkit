# 📈 Scaling In — when to add to a position

!!! abstract "From practice (229 mentions in the archive)"
    «Scaling in» — adding to an **already profitable** position to increase your gain.

    Important: this is **not averaging down** a losing position (that method destroys accounts).

---

## 🎯 What correct scaling in looks like

### ❌ WRONG (averaging a loss)

```
BUY 0.01 @ 1.0850   ← opened
Price goes DOWN to 1.0820 (minus 30 pips)
BUY 0.02 @ 1.0820   ← added "to improve the average"
Price goes to 1.0790 (minus another 30)
BUY 0.04 @ 1.0790   ← added again
...

Result: account destroyed.
This is gambling, not trading.
```

### ✅ RIGHT (scaling into a profit)

```
BUY 0.01 @ 1.0850   ← opened, risk 1% of account
Price goes UP to 1.0875 (+25 pips profit)
First move SL to BE (see "Safe")
Now risk = 0
BUY 0.01 @ 1.0875   ← scale-in #1 on HH breakout

Price reaches 1.0900
Move SL of both positions above the scale-in entry
BUY 0.01 @ 1.0900   ← scale-in #2

When the trend stops — close everything.
```

---

## 📐 Scaling-in rules

### Rule 1: "Safe" first, then scale in

**Do not add to a position that still carries a loss risk.**

First:
1. Move the base position SL to breakeven
2. Wait for confirmation of the move (new HH / LL)
3. Only then — scale in

### Rule 2: Scale-in lot = base position lot (or smaller)

```
Base position: 0.01
Scale-in #1: 0.01 (or 0.005)
Scale-in #2: 0.005 (even smaller)
```

**Never increase the lot on a scale-in!** "I'm confident, I'll put 0.05" = a big mistake.

### Rule 3: Scale in only on a level breakout

Not "on gut feeling", but **on structure**:
- For BUY: breakout of the previous HH (Higher High)
- For SELL: breakout of the previous LL (Lower Low)

### Rule 4: No more than 2–3 scale-ins

```
Base position → scale-in 1 → scale-in 2 → STOP
```

If you are making 4–5 scale-ins on a single wave — that is **pride and greed**, not strategy.

### Rule 5: On the last scale-in, tighten SL under the previous one

```
Base @ 1.0850 → SL 1.0850 (BE)
Scale-in 1 @ 1.0875 → SL of both 1.0865 (protects 15 pips on the base)
Scale-in 2 @ 1.0900 → SL of all 1.0885 (protects 25 pips of profit)
```

## 🎯 When to scale in and when NOT to

### ✅ It MAKES SENSE to scale in:

- A strong trending day (e.g. after FOMC)
- Breakout of a key level with confirmation
- In a swing (H4+) after consolidation
- The base position is already at breakeven
- High volatility in the market (Gold, EUR/USD on news)

### ❌ It does NOT make sense to scale in:

- In a flat / sideways market
- On Friday evening (position close is coming soon)
- If the base position is not yet at breakeven
- 1–2 hours before a red news event
- If you are already euphoric and "see it all clearly"

## 🔢 Scaling-in math

### Without scaling in:

```
1 position, lot 0.01
Move: +100 pips
Profit: $10 (1 pip = $0.10)
```

### With correct scaling in:

```
Base 0.01 @ 1.0850 → +100 pips = $10
Scale-in 1 (0.01) @ 1.0875 → +75 pips = $7.50
Scale-in 2 (0.005) @ 1.0900 → +50 pips = $2.50

Total: $20 on the same risk (because the base is at BE)
```

**Scaling in doubles the return with proper protection.**

### With incorrect scaling in (averaging):

```
Base 0.01 @ 1.0850 → -30 pips = -$3
"Averaging" 0.02 @ 1.0820 → -30 pips = -$6
"Averaging again" 0.04 @ 1.0790 → -30 pips = -$12
Price drops another -50 → stopped out on everything = -$50+

TOTAL: -$71 on a trade that should have been a $3 risk.
```

## ⚠️ The biggest scaling-in mistakes

### ❌ "I'm confident, I'll put in a huge scale-in"

This is an emotional decision. The scale-in lot must be **strictly ≤** the base lot.

### ❌ Scaling in without moving SL

The most dangerous mistake: you added a position, didn't tighten the SL, the market reversed — you lose two positions at once.

### ❌ Scaling in the opposite direction "to hedge"

This creates chaos in your head. If you want a hedge — close the position and open a new one in the opposite direction.

### ❌ Scaling in a third or fourth time without analysis

After 2 scale-ins **always** evaluate:
- Is the account over-exposed?
- Are we at the top of the move?
- What does the technical analysis say?

## 📊 Scaling In vs Pyramiding vs Martingale

| Method | What it is | Safe? |
|---|---|---|
| **Scaling in (correct)** | Adding to a profit with a protected base | ✅ Yes |
| **Pyramiding** | Same as scaling in, in trading literature | ✅ Yes |
| **Martingale** | Doubling the lot after a loss | ❌ Guaranteed account death |
| **Averaging down** | Adding to a loss | ❌ Destroys accounts |
| **Hedge-grid** | Grid of orders in both directions | ⚠️ Very risky for beginners |

**For beginners: ONLY scale into a profit with a protected base. Full stop.**

---

## ✅ Correct scaling-in checklist

Before every scale-in:

- [ ] Base position is already at BE (SL = entry)
- [ ] Scale-in lot ≤ base lot
- [ ] This is a scale-in on a level breakout (HH / LL), not "on gut feeling"
- [ ] I am not on scale-in 3+ (maximum 2)
- [ ] More than 1 hour until a red news event
- [ ] After adding I immediately tighten the SL on both positions
- [ ] Total risk is still within 2–3% of the account
