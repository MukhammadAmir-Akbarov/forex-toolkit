# Offline-режим

Нет соединения с сетью. Ранее открытые страницы и основные калькуляторы доступны
из локального кеша. Введённые данные и журнал остаются в браузере.

Когда новая offline-версия будет готова, сайт покажет уведомление. Обновление
применяется только после нажатия кнопки, поэтому незавершённый ввод не пропадёт.
