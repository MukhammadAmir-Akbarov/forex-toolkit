# Bot — детектор сигналов и бэктестер

> **⚠️ ВАЖНО: это НЕ живой торговый бот.**
>
> Этот код не подключается к брокеру и не открывает реальных ордеров. Это **учебный инструмент** для:
> - Понимания, как стратегия выражается в коде
> - Прогона стратегии на исторических данных (бэктест)
> - Расчёта статистики: win rate, profit factor, expectancy, drawdown
>
> Прежде чем подключать что-либо к реальному счёту, нужно как минимум: год опыта на демо, понимание API брокера, обработка ошибок, защита от багов, ограничители риска, тесты.

## Запуск

```bash
# Из корня проекта, после активации venv
.venv/bin/python bot/backtest.py

# С сохранением списка сделок и графика
.venv/bin/python bot/backtest.py --out my-curve.png --trades-csv my-trades.csv

# На своих CSV-данных
.venv/bin/python bot/backtest.py --csv ../data/eurusd_h1.csv

# С другим R:R
.venv/bin/python bot/backtest.py --rr 3.0
```

## Что значит вывод

```
Всего сделок:         9
Прибыльных:           5
Убыточных:            4
Win rate:             55.6%
Средний win:          +2.00R
Средний loss:         −1.00R
Profit Factor:        2.50
Expectancy:           +0.67R / сделку
Итого:                +6.00R
Макс. просадка:       1.00R
```

- **R** — единица риска (1R = твой стоп). +2R значит «взял в 2 раза больше, чем рискнул».
- **Win rate 55.6%** — доля прибыльных сделок.
- **Profit Factor 2.50** — на каждый $1 убытка приходится $2.50 прибыли. Хорошо.
- **Expectancy +0.67R** — ожидаемый результат **одной** сделки. На 100 сделках = +67R прибыли.
- **Max drawdown 1.00R** — максимальная просадка от пика.

## Equity curve

После запуска создаётся файл `equity-curve.png` с кумулятивным результатом:

![Equity curve пример](https://raw.githubusercontent.com/MukhammadAmir-Akbarov/forex-toolkit/main/bot/equity-curve.png)

Хорошая equity curve **идёт слева вниз направо вверх с управляемыми просадками**. Резкие падения, нулевая или отрицательная динамика — сигнал, что стратегия не работает.

## Что НЕ делает этот бот (намеренно)

- ❌ Не подключается к MetaTrader / cTrader / API брокера
- ❌ Не открывает реальные ордера
- ❌ Не учитывает спред, комиссию, проскальзывание, свопы (для упрощения)
- ❌ Не использует multi-timeframe анализ (упрощённо использует EMA200 на текущем TF)
- ❌ Не имеет новостного фильтра

Эти ограничения важны: **реальный результат на счёте всегда хуже бэктеста**. Учитывай это.

## Как «улучшать» бэктест честно

1. **Не подгоняй параметры**. Если ты крутишь RSI пороги, пока не получишь идеальный график — это **overfitting**, в реальности не сработает.
2. **In-sample / out-of-sample**: настраивай на одной половине данных, проверяй на второй.
3. **Walk-forward**: тестируй на последовательных окнах истории, не на одном.
4. **Учти спред**: вычти 1–2 пипса от прибыли каждой сделки.
5. **Реальный win rate на демо обычно на 5–10% хуже** бэктеста из-за психологии и исполнения.

## Формат CSV для своих данных

Скачать исторические данные можно бесплатно с:
- [Dukascopy Historical Data](https://www.dukascopy.com/swiss/english/marketwatch/historical/)
- В терминале MT5: F2 → выгрузить в CSV
- TradingView: правая панель → Экспорт данных (для Pro-подписки)

Ожидаемые колонки:

```csv
datetime,open,high,low,close
2026-01-01 00:00:00,1.08500,1.08620,1.08480,1.08590
2026-01-01 01:00:00,1.08590,1.08650,1.08550,1.08610
...
```

## Путь от этого скрипта к реальному боту

**Это длинный путь.** Если когда-нибудь решишь:

1. **Минимум 6–12 месяцев** ручной торговли на демо с этой же стратегией. Если ручная не приносит плюса — алгоритм не спасёт.
2. **Изучить API брокера**: MetaTrader 5 имеет Python-пакет [`MetaTrader5`](https://pypi.org/project/MetaTrader5/) — но работает только на Windows.
3. **Сначала** торговать **только на демо** через бота минимум 3 месяца.
4. **Только после стабильной плюсовой торговли на демо-боте** — реальный счёт с минимальным депозитом.
5. **Никогда** не оставляй бота без присмотра. Краши, обновления MT5, баги в коде — всё это может слить депозит за час.

## Дисклеймер

Образовательный код. Не использовать на реальных счетах в текущем виде. Прошлая статистика бэктеста не гарантирует будущие результаты. Автор кода не несёт ответственности за решения, принятые на его основе.
