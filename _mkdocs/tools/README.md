## position_calculator.py

Считает размер позиции в лотах на основе твоего риск-менеджмента.

### Интерактивный режим

```bash
.venv/bin/python tools/position_calculator.py
```

```
=== Калькулятор размера позиции ===

Депозит ($): 1000
Риск на сделку (%, например 0.5): 0.5
Стоп-лосс (в пипсах): 25
Пара (EURUSD / GBPUSD / USDJPY / ...): EURUSD

╭─────────────────────────────────────────╮
│  КАЛЬКУЛЯТОР РАЗМЕРА ПОЗИЦИИ            │
╰─────────────────────────────────────────╯

Входные данные:
  Депозит:           $1,000.00
  Риск:              0.50% = $5.00
  Стоп-лосс:         25 пипсов
  Пара:              EURUSD
  Стоимость пипса:   $10.00 за 1 лот

Расчёт:
  Размер (точный):   0.0200 лота
  Размер (округл.):  0.02 лота
  Реальный риск:     $5.00 (0.50%)

→ Выстави в терминале: 0.02 лота
```

### Однострочный режим

```bash
.venv/bin/python tools/position_calculator.py --balance 1000 --risk 0.5 --stop 25 --pair EURUSD
```

### Параметры

| Флаг | Что значит |
|---|---|
| `--balance` / `-b` | Депозит в USD |
| `--risk` / `-r` | Процент риска (0.5 = 0.5%) |
| `--stop` / `-s` | Расстояние до стоп-лосса в пипсах |
| `--pair` / `-p` | Валютная пара (EURUSD по умолчанию) |
| `--list-pairs` | Показать список поддерживаемых пар |

### Логика округления

Размер всегда округляется **вниз** до 0.01 (минимальный шаг у большинства брокеров). Это значит **реальный риск меньше** запланированного, что безопаснее.

Минимум 0.01 лота. Если расчёт даёт меньше (маленький депозит + большой стоп), скрипт предупреждает: реальный риск может превысить заданный.

### Предупреждения

- ⚠️ Если реальный риск > запланированного (из-за округления) — предложит уменьшить ручную позицию.
- ⚠️ Если реальный риск > 2% депозита — предупреждение, что это много для новичка.

## chart_generator.py

Генерирует PNG-картинки для документации. Используется один раз — все картинки уже сгенерированы в `docs/images/`. Перезапуск нужен только если ты хочешь изменить визуальный стиль или добавить новые иллюстрации.

```bash
.venv/bin/python tools/chart_generator.py
```

Создаёт:

- `candle-anatomy.png` — анатомия японской свечи
- `candle-patterns.png` — молот, поглощение, доджи, падающая звезда
- `trend-types.png` — типы трендов (вверх / вниз / флэт)
- `support-resistance.png` — уровни поддержки и сопротивления
- `ema-example.png` — EMA 50 и EMA 200
- `rsi-example.png` — индикатор RSI
- `macd-example.png` — индикатор MACD
- `bollinger-example.png` — Bollinger Bands
- `chart-patterns.png` — голова и плечи, треугольник, двойная вершина
- `strategy-example.png` — иллюстрация сетапа стратегии
- `risk-reward.png` — таблица win rate × R:R
- `drawdown-math.png` — математика разорения

Все данные **синтетические** — для иллюстрации концепций, не реальные котировки.
