# 🎮 Тренажёр Replay — торгуй прошлым рынком

!!! abstract "Что это такое"
    Тренажёр показывает реальные архивные свечи **EURUSD, GBPUSD, USDJPY и
    EURJPY** на **H1 и D1**. Ты выбираешь рынок, направление и ставишь
    **Entry / SL / TP прямо на графике**. Затем виджет доигрывает будущие свечи
    и показывает результат в **R-кратном**.

    **R-кратное = прибыль / размер стопа.** Твоя цель: стабильно получать +R
    (тейк-профит 2R, стоп 1R → отношение 1:2).

!!! tip "Как тренироваться правильно"
    1. Смотри только на свечи — не думай «это уже было…»
    2. Выбери Buy/Sell, затем по очереди кликни уровни Entry, SL и TP
    3. Проверь порядок уровней и только потом запускай Replay
    4. После сессии повтори убыточные эпизоды отдельной кнопкой

!!! warning "Образовательный материал — не финансовый совет"
    Все эпизоды взяты из архивных данных. Прошлая доходность не гарантирует
    будущих результатов. Торговля на форекс сопряжена с высоким риском потерь.

## Как читать результат

| Метрика | Что значит |
|---|---|
| **+2.0R** | Прибыль вдвое больше стопа (тейк на 2R сработал) |
| **-1.0R** | Стоп-лосс сработал (потеря равна выставленному стопу) |
| **WinRate** | Процент прибыльных сделок из всех входов (без скипов) |
| **Avg R** | Среднее R за сессию — должно быть > 0 |

!!! note "Статистика сохраняется в браузере"
    Итог сессии, слабая категория рынка и список ошибочных эпизодов сохраняются
    в `localStorage`. Личный кабинет использует их для следующей рекомендации.

!!! info "Клавиатура и доступность"
    Нажми **B** для Buy, **S** для Sell, **Space** для пропуска и используй
    стрелки для выбора и перемещения уровней. Под графиком можно открыть
    текстовое описание и таблицу последних свечей. Видимый контур показывает,
    когда фокус находится на графике.

Если в журнале создана персональная задача, Replay показывает её над графиком и
засчитывает прогресс после подходящих упражнений.

## Пересобрать набор эпизодов

Эпизоды сгенерированы скриптом [`tools/replay_cutter.py`](https://github.com/MukhammadAmir-Akbarov/forex-toolkit/blob/main/tools/replay_cutter.py)
из архива `data/EURUSD_1h.csv`:

```bash
python tools/replay_cutter.py \
  --pairs EURUSD,GBPUSD,USDJPY,EURJPY \
  --timeframes 1h,1d \
  --episodes 10 --context 30 --outcome 15 \
  --output _mkdocs/data/replay-episodes.json
```

`--episodes` задаёт число эпизодов **на каждый рынок и таймфрейм**: сейчас
их 10, то есть 80 на все восемь связок. Скрипт растягивает выборку по всему
архиву (D1 — с 2021 года), не даёт эпизодам перекрываться и держит смесь
трендов и боковика. Скрипт
правильно учитывает размер пипса JPY-пар и балансирует тренд/флэт.
