# 🎮 Тренажёр Replay — торгуй прошлым рынком

!!! abstract "Что это такое"
    Тренажёр показывает **реальные свечи EURUSD H1** из архива — ты видишь историю
    до точки X, принимаешь решение (Buy / Sell / Пропустить) и выставляешь стоп-лосс.
    Затем виджет доигрывает будущие свечи и показывает результат в **R-кратном**.

    **R-кратное = прибыль / размер стопа.** Твоя цель: стабильно получать +R
    (тейк-профит 2R, стоп 1R → отношение 1:2).

!!! tip "Как тренироваться правильно"
    1. Смотри только на свечи — не думай «это уже было…»
    2. Выставляй стоп **до** нажатия Buy/Sell — это обязательное условие
    3. Цель не угадать, а принять решение по **своим правилам**
    4. После 20 эпизодов сравни свою статистику с ожидаемым EV

!!! warning "Образовательный материал — не финансовый совет"
    Все эпизоды взяты из архивных данных. Прошлая доходность не гарантирует
    будущих результатов. Торговля на форекс сопряжена с высоким риском потерь.

## Как читать результат

| Метрика | Что значит |
|---|---|
| **+2.0R** | Прибыль вдвое больше стопа (тейк на 2R сработал) |
| **-1.0R** | Стоп-лосс сработал (потеря равна выставленному стопу) |
| **WinRate** | Процент прибыльных сделок из всех входов (без скипов) |
| **Avg R** | Среднее R за сессию — должно быть > 0 |

!!! note "Статистика сохраняется в браузере"
    Результаты каждой сессии хранятся в `localStorage`. При следующем визите
    прогресс не сохраняется — каждая сессия начинается с нуля.

## Пересобрать набор эпизодов

Эпизоды сгенерированы скриптом [`tools/replay_cutter.py`](https://github.com/MukhammadAmir-Akbarov/forex-toolkit/blob/main/tools/replay_cutter.py)
из архива `data/EURUSD_1h.csv`:

```bash
python tools/replay_cutter.py \
  --pair EURUSD --tf 1h \
  --episodes 20 --context 30 --outcome 15 \
  --output _mkdocs/data/replay-episodes.json
```

Флаги `--context` (свечей истории) и `--outcome` (свечей будущего) можно менять.
Скрипт автоматически балансирует категории: ≈1/3 восходящий тренд,
1/3 нисходящий, 1/3 флэт.
