# 🎓 Итоговый экзамен + сертификат

!!! abstract "Как это работает"
    Каждая попытка — **20 случайных вопросов из банка в 30**, и варианты
    ответа тоже перемешиваются. Зазубрить порядок не выйдет. Темы: риск-
    менеджмент, расчёт объёма, издержки, психология, механика рынка.
    Проходной балл — **80%** (16 из 20). Сдашь — получишь **именной
    PNG-сертификат**, который можно скачать и показать.

    Больше половины вопросов — на расчёт и разбор ситуации, а не на
    запоминание определений. Не сдал — экзамен покажет, какие темы
    перечитать. Лучший результат хранится в браузере.

!!! warning "Образовательный материал — не финансовый совет"
    Правильные ответы отражают принципы управления риском, а не гарантию прибыли.
    Сертификат подтверждает прохождение учебного курса, а не квалификацию трейдера.
