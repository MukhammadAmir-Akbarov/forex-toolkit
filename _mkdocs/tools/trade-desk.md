# Перед сделкой

Один последовательный экран: рассчитать позицию, пройти предторговый чек-лист
и сохранить план для журнала. Данные остаются в браузере.

<div id="trade-desk-widget" class="fx-tool"></div>

!!! tip "После сохранения"
    Нажми **«Открыть план в журнале»**. Там переведи сделку из статуса
    **План** в **Открыта**, а после закрытия добавь результат, комиссию и разбор.
    Первоначальная причина входа сохранится без изменения. CSV остаётся запасным экспортом.

Для нескольких одновременных сделок сначала используй
[калькулятор совокупного риска](risk-exposure-calculator.md).
