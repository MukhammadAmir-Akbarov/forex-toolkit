# 🏦 Брокеры для трейдеров из Узбекистана

!!! warning "Образовательный материал"
    Этот раздел — обзор известных вариантов. **Не реклама.** Перед открытием счёта **сам проверь** актуальную регуляцию, отзывы и условия.

## Регулирование

В Узбекистане **нет специального forex-регулятора**. Местные банки не предоставляют forex-торговлю напрямую. Большинство узбекских трейдеров используют **зарубежных брокеров**, регулируемых известными органами:

| Регулятор | Страна | Уровень доверия |
|---|---|---|
| **FCA** | Великобритания | 🟢 Очень высокий |
| **CySEC** | Кипр / EU | 🟢 Высокий (EU стандарт) |
| **ASIC** | Австралия | 🟢 Высокий |
| **FSCA** | ЮАР | 🟡 Средний |
| **CBCS** | Кюрасао | 🔴 Низкий (быстрая регистрация) |
| **SVG FSA** | Сент-Винсент | ⛔ Не считается реальной регуляцией |

**Правило**: чем строже регулятор, тем сложнее с него «забрать деньги», но и меньше шансов попасть на скам.

## Известные брокеры (нужна верификация)

!!! danger "Не верь этому списку — проверь сам"
    Этот список составлен на дату последнего коммита. Брокеры **закрываются, меняют условия, попадают под санкции**. Перед открытием счёта:

    1. Проверь актуальный статус регуляции на сайте регулятора
    2. Поищи свежие отзывы на ForexPeaceArmy / Trustpilot
    3. Открой только **демо-счёт** первым — посмотри работу
    4. Реальный депозит — не более $100 для теста вывода

### Категории (без рекомендаций)

- **Глобальные ECN-брокеры с регуляцией FCA/ASIC**: IC Markets, Pepperstone, FP Markets
- **Маркет-мейкеры с регуляцией CySEC**: XM, Exness, FxPro, HF Markets
- **Дешёвые офшорные**: предлагают высокое плечо, но защиты средств минимальная

## Особенности для УЗ

### Способы пополнения / вывода

См. [Гид по выводу денег](withdrawal-guide.md) (подробный).

Кратко:
- **Visa/Mastercard**: работает в обе стороны, комиссия 1-3%
- **USDT (Tether)**: самый дешёвый и быстрый — через Binance / Bybit
- **Wise / Payeer**: посредник, есть лимиты
- **SWIFT-перевод**: только для крупных сумм ($5000+)

### Налогообложение

В Узбекистане прибыль от forex формально облагается **12% НДФЛ**. На практике налоговая редко проверяет, но **это твоя обязанность** задекларировать. См. `uz/tax-calculator.py` для расчёта.

### Связь со страной

Хороший брокер **не должен ограничивать** UZ-резидентов. Если требуют VPN или прокси для регистрации — это плохой знак.

## Чек-лист выбора брокера

- [ ] Регуляция: FCA, ASIC или CySEC (минимум)
- [ ] Спред EUR/USD на ECN-счёте: ≤ 1 пипса (без комиссии: ≤ 1.5)
- [ ] Минимальный депозит: ≤ $100
- [ ] Микро-лоты доступны (0.01)
- [ ] Поддержка на русском или английском (не машинный перевод)
- [ ] Вывод денег за ≤ 5 рабочих дней
- [ ] Отзывы > 3.5 на независимых платформах (минимум 100 отзывов)
- [ ] Не упоминают «гарантированную прибыль» в маркетинге
