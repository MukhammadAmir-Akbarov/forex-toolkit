# Streamlit Setup Guide — интерактивный бэктест в браузере

## Что это даёт

После запуска ты получишь **веб-страницу со слайдерами**, где можешь:
- Выбрать стратегию из выпадающего списка
- Двигать слайдер R:R, win rate, число свечей
- Сразу видеть **обновлённую** equity curve, метрики, таблицу сделок
- График цены с маркерами сигналов

Это намного удобнее, чем перезапускать Python-скрипт с разными параметрами.

## Шаг 1: Установка Streamlit

```bash
cd /Users/mukhammadamir/Sites/WORK/trading
.venv/bin/pip install streamlit plotly
```

Это установит Streamlit (~30 МБ).

## Шаг 2: Запуск

```bash
.venv/bin/streamlit run advanced/streamlit_app.py
```

Что произойдёт:
1. В терминале появится сообщение:
   ```
   You can now view your Streamlit app in your browser.
   Local URL: http://localhost:8501
   ```
2. **Браузер сам откроется** на http://localhost:8501
3. Если не открылся — открой ссылку вручную

## Шаг 3: Использование

### Левая панель (сайдбар) — параметры

- **Стратегия** — выбор из 4 стратегий
- **Свечей в выборке** — сколько H1-свечей сгенерировать (больше = больше сделок)
- **R:R** — соотношение Risk/Reward (1.0–5.0)
- **Random seed** — для воспроизводимости (одно и то же число = одни и те же данные)
- **Риск на сделку** — для расчёта итогового %

### Главная часть страницы

1. **Метрики** сверху (4 карточки):
   - Сделок
   - Win rate
   - Profit Factor
   - Итого

2. **Equity curve** — интерактивный график
   - Наведи мышь — увидишь точные значения
   - Можно зумировать

3. **Таблица сделок** — последние 50 сделок

4. **Ценовой график со свечами** — увидишь маркеры сигналов (▲ long, ▼ short)

## Шаг 4: Эксперименты

Попробуй:

### Эксперимент 1: Влияние R:R
- Двинь R:R с 1.0 на 5.0
- Смотри, как меняется итоговая прибыль
- **Вывод:** при больших R:R меньше сделок успешны, но каждая выгоднее

### Эксперимент 2: Сравнение стратегий
- Меняй стратегию (EMA50 → Mean Reversion → Breakout → Three Soldiers)
- Один и тот же seed = одни и те же данные
- **Вывод:** какая лучше на этих данных?

### Эксперимент 3: Зависимость от данных
- Меняй random seed (1, 42, 100, 9999)
- Одна и та же стратегия будет давать **очень разные** результаты
- **Вывод:** результат зависит от удачи + кол-ва данных

## Шаг 5: Остановка приложения

В терминале нажми **Ctrl+C** — Streamlit остановится.

Чтобы запустить снова — повторить шаг 2.

## Запуск на фоне (опционально)

Если хочешь, чтобы Streamlit работал постоянно:

```bash
.venv/bin/streamlit run advanced/streamlit_app.py &
```

И закроешь, когда не нужно:
```bash
pkill -f streamlit
```

## Доступ с другого устройства (опционально)

По умолчанию Streamlit виден только на твоём ноуте. Чтобы открыть с телефона в той же Wi-Fi сети:

```bash
.venv/bin/streamlit run advanced/streamlit_app.py --server.address 0.0.0.0
```

Затем на телефоне открой:
```
http://<IP-твоего-Mac>:8501
```

IP узнать: `ifconfig | grep "inet 192"`

## Развёртывание в облаке (для продвинутых)

1. Загрузи проект на GitHub
2. Зарегистрируйся на streamlit.io/cloud
3. Подключи репозиторий → выбери `advanced/streamlit_app.py`
4. Получишь публичный URL

**⚠️** Не выкладывай журнал сделок с реальными данными в публичный репозиторий.

## Troubleshooting

### `streamlit: command not found`
Запускай через `.venv/bin/streamlit`, а не просто `streamlit`.

### Браузер не открылся
Открой вручную: http://localhost:8501

### Порт 8501 занят
```bash
.venv/bin/streamlit run advanced/streamlit_app.py --server.port 8502
```

### Streamlit падает с ошибкой импорта
Проверь, что все зависимости установлены:
```bash
.venv/bin/pip install streamlit plotly pandas numpy matplotlib
```

### Графики не обновляются
- Очисти кэш: в правом верхнем углу страницы → меню → **Clear cache**
- Перезагрузи страницу (Cmd+R)

## Что внутри (для интересующихся)

Файл [streamlit_app.py](streamlit_app.py) — это веб-приложение в ~150 строк Python:
- `st.sidebar` — левая панель
- `st.slider`, `st.selectbox` — элементы управления
- `st.cache_data` — кэширование, чтобы при каждом изменении не пересчитывать всё
- `plotly.graph_objects` — интерактивные графики
- Логика бэктеста та же, что в `bot/backtest.py`

Можешь редактировать файл и сразу видеть изменения (Streamlit перезагружает страницу автоматически).
