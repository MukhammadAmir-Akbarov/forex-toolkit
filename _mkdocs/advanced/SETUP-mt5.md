# MT5 Setup Guide — пошаговая установка MetaTrader 5

## Шаг 1: Регистрация у брокера

1. Выбери регулируемого брокера (см. [extras/brokers-comparison.md](../extras/brokers-comparison.md))
2. На сайте брокера → **«Открыть демо-счёт»** (не реальный!)
3. Заполни форму: имя, email, телефон
4. Получи на email **3 значения**:
   - **Login** (например 50123456)
   - **Password** (investor password — для просмотра, master password — для торговли)
   - **Server** (например `Exness-Demo` или `ICMarkets-Demo01`)

> ⚠️ Сохрани эти данные. Они нужны для входа в MT5.

## Шаг 2: Скачивание MT5

### macOS

MetaTrader 5 для Mac есть в двух вариантах:

**Вариант А: нативный (рекомендую)**
1. Открой сайт твоего брокера → раздел **«Скачать MT5»** → **Mac**
2. Скачается `.dmg` файл (~60 МБ)
3. Открой → перетащи MT5 в Applications
4. Запусти → разреши в Системных настройках если macOS заблокирует

**Вариант Б: через WINE (если нативный не работает)**
1. Скачай **MetaTrader 5** с сайта metaquotes.net
2. Установи Wine: `brew install --cask wine-stable`
3. Открой .exe через Wine

### Windows
1. Сайт брокера → Download → Windows
2. Запусти .exe → установи

### Linux
1. WINE: `sudo apt install wine`
2. Скачай Windows .exe → запусти через Wine

## Шаг 3: Первый вход

1. Запусти MT5
2. Меню: **File → Login to Trade Account**
3. Заполни:
   ```
   Login:    [твой логин от брокера]
   Password: [пароль]
   Server:   [сервер из письма]
   ```
4. Поставь галочку **«Save account info»**
5. Нажми **Login**

✅ В нижнем правом углу увидишь зелёные цифры — баланс, equity, margin.

## Шаг 4: Настройка графика

### Включить свечной график
- Правая кнопка по графику → **Candlesticks**
- Или нажать кнопку «свечи» в верхней панели

### Переключить таймфрейм на H1
- Верхняя панель: M1, M5, M15, M30, **H1**, H4, D1, W1
- Кликни **H1**

### Добавить EMA 50
1. **Insert → Indicators → Trend → Moving Average**
2. Параметры:
   - Period: **50**
   - MA method: **Exponential**
   - Apply to: **Close**
   - Style: цвет — **синий**, толщина **2**
3. OK

### Добавить EMA 200
Повторить, но Period = **200**, цвет — **красный**.

### Добавить RSI
1. **Insert → Indicators → Oscillators → Relative Strength Index**
2. Period: **14**
3. Apply to: **Close**
4. OK

### Сохранить шаблон
Чтобы не настраивать каждый раз:
- Правая кнопка по графику → **Templates → Save Template** → имя «MyTemplate»
- В следующий раз: правая кнопка → Templates → MyTemplate

## Шаг 5: Открытие сделки

### Правильный способ открытия (с SL/TP сразу)

1. Нажми **F9** (или кнопка «New Order» в верхней панели)
2. Окно ордера:
   ```
   Symbol:        EURUSD
   Volume:        0.01     ← рассчитай через position_calculator.py!
   Stop Loss:     1.0827   ← обязательно!
   Take Profit:   1.0902   ← обязательно!
   Type:          Market Execution
   ```
3. Нажми **Buy by Market** (long) или **Sell by Market** (short)

### Распространённые ошибки

❌ **Открыть без SL** → Никогда. Сначала введи SL.
❌ **Объём «на глаз»** → используй калькулятор.
❌ **«Type: Pending»** → это отложенный ордер, ты ждёшь, что цена дойдёт. Сейчас тебе не нужно.

## Шаг 6: Проверка сделки

После открытия в нижней панели **Trade**:
```
Symbol  Type  Volume  Open Price  S/L      T/P      Profit
EURUSD  buy   0.01    1.08520    1.08270  1.09020  +$1.50
```

✓ S/L и T/P **не пустые** — значит, защита стоит.

## Шаг 7: Закрытие сделки

**Лучший вариант:** не закрывай руками. Жди, пока сработает SL или TP.

**Если нужно закрыть досрочно** (только в исключительных случаях):
- Правая кнопка по сделке внизу → **Close Order**

## Шаг 8: Журнал сделок в MT5

MT5 сам ведёт лог:
- Нижняя панель → **History**
- Видишь все закрытые сделки с результатами
- Можно экспортировать: правая кнопка → **Report → Save as Report (HTML)**

Эту историю стоит **параллельно** копировать в свой Markdown/CSV журнал, потому что в MT5 нет полей «эмоции», «следовал правилам» и т.д.

## Шаг 9: Часто используемые горячие клавиши

| Клавиша | Что |
|---|---|
| **F9** | Открыть New Order |
| **F8** | Свойства графика |
| **F11** | Полноэкранный режим |
| **Ctrl+T** | Терминал внизу |
| **Ctrl+N** | Окно Navigator |
| **+** / **−** | Zoom in / out |
| **PageDown** | К последним свечам |

## Шаг 10: Установка нашего Expert Advisor

Если хочешь запустить наш [EMA50Pullback.mq5](EMA50Pullback.mq5) на демо:

1. В MT5: **File → Open Data Folder**
2. Открой папку `MQL5/Experts/`
3. Скопируй туда файл `EMA50Pullback.mq5`
4. В MT5: **View → Navigator** (Ctrl+N)
5. Раздел **Expert Advisors** → правая кнопка → **Refresh**
6. Увидишь `EMA50Pullback` → перетащи на график EUR/USD H1
7. В окне настроек:
   - ✅ **Allow live trading** (только если хочешь, чтобы советник торговал)
   - Установи параметры (Risk_Percent, Risk_Reward и т.д.)
   - **OK**
8. В верхнем правом углу графика увидишь смайлик 😀 (работает) или ❌ (не работает)

**⚠️ ВАЖНО:** EA защищён проверкой «только демо». На реальном счёте он откажется работать.

## Шаг 11: Демо-счёт vs реал — главные отличия

| Особенность | Демо | Реал |
|---|---|---|
| Исполнение | Идеальное | С проскальзыванием |
| Спред | Часто меньше | Реальный, может расширяться |
| Эмоции | Нет (виртуальные) | Есть (твоя проблема) |
| Свопы | Иногда упрощены | Реальные |
| Реквоты | Нет | Возможны при сильной волатильности |

## Шаг 12: Стратегия первого месяца на MT5

Неделя 1:
- Установка, привыкание к интерфейсу
- 5-10 пробных сделок с минимальным объёмом 0.01 лот
- Тестировать SL/TP — убедиться, что работают

Неделя 2-4:
- Торговля по правилам стратегии (1-3 сделки в день)
- Параллельно ведение журнала
- Использование калькулятора перед каждой сделкой

## Дополнительные советы

### Если терминал зависает
- Закрой все вкладки лишних графиков
- В правом нижнем углу: правая кнопка → **Connect Status** → должно быть «Connected»
- Если нет — переподключись через File → Login

### Если котировки не обновляются
- Возможно, твой брокер ограничивает квоты в выходные
- Проверь, что не суббота/воскресенье (рынок закрыт)

### Резервная копия настроек
- File → Open Data Folder → скопируй папку `config/`
- В будущем восстановишь нажав «Restore»
