# 🌍 Fundamental tahlil — iqtisodiyot orqali bozorni o'qish

!!! abstract "Fundamental tahlil nima"
    Texnik tahlil «**qaerda**» degan savolga javob beradi — qaysi darajada kirish kerak.
    Fundamental tahlil «**nima uchun**» degan savolga javob beradi — umuman narxni nima
    harakatlantiradi. Iqtisodchi bo'lishning hojati yo'q: bozor harakatlarining 80%ini
    tushuntiradigan 5–6 ta asosiy tushunchani o'zlashtirish kifoya.

> **Ta'lim materiali.** Ma'lumotlar va misollar tarixiy bo'lib, faqat tushuntirish maqsadida.

## 1. Valyutani nima harakatlantiradi — uch manba

### Manba 1: Foiz stavkalari va stavka kutilmalari

Eng muhim omil. Pul daromadi yuqori bo'lgan tomonga oqadi.

```
Fed stavkasi = 5,5%
ECB stavkasi = 4,0%
→ Dollarda saqlash foydali → USD EUR dan kuchli
→ EUR/USD bosim ostida
```

### Manba 2: Iqtisodiy o'sish

Kuchli iqtisodiyot → kompaniyalar investitsiya qiladi → mahalliy valyutaga talab → kurs ko'tariladi.

### Manba 3: Risk ishtahasi (Risk On / Risk Off)

Investorlar ishonchli bo'lganda → «xavfli» aktivlar (yuqori daromadli valyutalar, aksiyalar) oladi.
Qo'rquv bo'lganda → «xavfsiz» aktivlarga qochadi.

| Stsenariy | Risk ON | Risk OFF |
|---|---|---|
| Kuchayadi | AUD, NZD, CAD, EUR | USD, JPY, CHF |
| Zaiflashadi | USD, JPY, CHF | AUD, NZD, yuqori daromadlilar |
| Sabab | Ijobiy ma'lumotlar, aksiyalar o'sishi | Retsessiya, inqiroz, geopolitika |

## 2. Foiz stavkalari — asosiy harakatlantirgich

### Carry Trade — mohiyati

```
JPY ni 0,1% ga qarzga olasiz
AUD aktivlarini 4,5% daromad bilan sotib olasiz
Daromad = yiliga 4,4% (kurs o'zgarishisiz)
```

Millionlab treyderlar shunday qilganda — AUD JPY ga nisbatan ko'tariladi.
Qo'rquv (inqiroz) bo'lganda → barcha «carry ni yopadi» → AUD qulaydi, JPY uchadi.

### Stavka differentsiali va kurs

```
EUR/USD va stavkalar (soddalashtirilib):
2022–2023: Fed ECB dan tezroq stavkani oshirdi
→ differentsial: 5,5% (USD) vs 4,0% (EUR) = USD foydasiga +1,5%
→ EUR/USD 1,11 dan 2022 yilda 0,96 gacha tushdi
2024–2025: Fed ECB dan tezroq tushirishni boshladi
→ differentsial torayadi → EUR/USD tiklanadi
```

### Haqiqiy stavka vs Nominal stavka

Nominaldan muhimroq — **haqiqiy stavka** (= nominal stavka − inflyatsiya):

```
AQSh stavkasi = 5,5%, inflyatsiya = 3,5% → haqiqiy = +2,0% (jozibador)
Yaponiya stavkasi = 0,1%, inflyatsiya = 2,5% → haqiqiy = −2,4% (jozibador emas)
→ Haqiqiy daromad bo'yicha USD JPY dan kuchli
```

## 3. Markaziy bank sikli

Markaziy banklar sikl bo'yicha harakat qiladi — va bu **bashorat qilinishi mumkin**.

```
Inflyatsiya o'sadi → MB STAVKANI OSHIRADI → valyuta kuchayadi
Stavkalar iqtisodiyotni bosadi → PAUZA / KUTISH → konsolidatsiya
O'sish sekinlashadi, ishsizlik o'sadi → MB STAVKANI TUSHIRADI → valyuta zaiflashadi
Rag'batlantirish yordam beradi → INFLYATSIYA O'SADI → boshiga qaytadi
```

### MB oldindan signal berish usuli

MBlar **deyarli hech qachon** to'satdan qaror qilmaydi (inqirozlardan tashqari).
Ular bozorni **«forward guidance»** — nutq va bayonotlardagi ishoralar orqali tayyorlaydi.

MB ritorikasidagi kalit so'zlar:

| Qattiq ritorika (Hawkish) | Yumshoq ritorika (Dovish) |
|---|---|
| «inflyatsiyadan xavotirdamiz» | «iqtisodiy zaiflashuvni kuzatmoqdamiz» |
| «qo'shimcha stavka oshirishlari kerak bo'lishi mumkin» | «kerak bo'lsa tushirishga tayyormiz» |
| «ma'lumotlarga bog'liq» (tushirish va'dasisiz) | «moslashuvchan siyosat» |
| «maqsaddan ancha yuqori» | «inflyatsiya tushmoqda» |

## 4. Iqtisodiy kalendarni o'qish usuli

### Voqea yozuvining tuzilishi

```
Juma, 7 iyun, 13:30 UTC
🔴 USD  Qishloq xo'jaligi sektor tashqari ish o'rinlari
         Oldingi: 175K
         Prognoz: 185K
         Haqiqiy: 272K  ← reliz paytida paydo bo'ladi
```

### Voqeani tahlil qilish algoritmi:

1. **Qaysi mamlakat?** → Uning valyutasiga bevosita ta'sir qiladi.
2. **Bu qanday ko'rsatkich?** → Mehnat? Inflyatsiya? O'sish?
3. **Ko'rsatkich trendi** — so'nggi 3–4 oy davomida yaxshilanmoqdami yoki yomonlashmoqdami?
4. **Prognoz va haqiqiy** — kutilmagan natija mutlaq qiymatdan muhimroq.
5. **Oldingi qayta ko'rib chiqish** — avvalgi qiymat ko'pincha o'zgartiriladi; bozor buni sezadi.

## 5. Inflyatsiya va uning Forexga ta'siri

### Asosiy inflyatsiya ko'rsatkichlari

| Ko'rsatkich | Mamlakat | Nima o'lchaydi | Muhimligi |
|---|---|---|---|
| **CPI** (Iste'mol narxlari indeksi) | AQSh, EU, UK | Iste'mol savati narxlari | 🔴🔴🔴 |
| **Core CPI** | AQSh | Oziq-ovqat va energiyas. CPI | 🔴🔴🔴 |
| **PCE** | AQSh | Fed ning sevimli ko'rsatkichi | 🔴🔴 |
| **PPI** (Ishlab chiqaruvchi narxlari ind.) | AQSh | Ulgurji narxlar (CPI uchun yetakchi) | 🟠🟠 |

### Inflyatsiyaning kursga ta'siri

```
Inflyatsiya o'sadi (2% maqsaddan yuqori) → MB stavkani oshirishi mumkin → valyuta kuchayadi
Stavka oshirilishi → valyuta jozibadorroq → kurs ko'tariladi

Inflyatsiya tushadi (2% dan past) → MB tushirishni ko'rib chiqadi → valyuta zaiflashadi
Stavkani tushirish → valyuta kamroq jozibador → kurs tushadi
```

!!! warning "Paradoks: yuqori inflyatsiya = qisqa muddatda valyuta kuchayadi"
    Qisqa muddatda: yuqori inflyatsiya = MB stavkani oshiradi = valyuta ko'tariladi.
    Uzoq muddatda: yuqori inflyatsiya = xarid qobiliyatining eroziyasi = valyuta zaiflashadi.
    **Forex kutilmalarga savdo qiladi** — muhimi inflyatsiya QAYERGA ketayotgani, hozir qayerda
    ekanligi emas.

## 6. Mehnat bozori — NFP va ishsizlik

### Non-Farm Payrolls (NFP)

**Har oyning birinchi juma kuni, 13:30 UTC da** e'lon qilinadi.
Bir oyda **nechta ish o'rni yaratilganini** ko'rsatadi (qishloq xo'jaligisiz).

```
> 200K yangi ish o'rni → kuchli mehnat bozori → Fed tushirishga kamroq sabab → USD ko'tariladi
< 100K → zaif bozor → Fed tushirishi mumkin → USD zaiflashadi
```

### O'rtacha soatlik ish haqi

Ko'pincha NFP dan muhimroq! Ish haqi → iste'molchi xarajatlari → inflyatsiya.
Yillik 4% dan yuqori ish haqi o'sishi = inflyatsiya bosimi = Fed tushirishga shoshilmaydi.

## 7. YIM — iqtisodiy salomatlikning aksi

**Yalpi ichki mahsulot** — mamlakatda ishlab chiqarilgan hamma narsaning umumiy qiymati.

### Bir chorak uchun uch marta e'lon qilinadi:

```
YIM Oldindan Baholash  → birinchi, dastlabki (eng muhimi)
YIM Ikkinchi Baholash  → bir oydan keyin, tuzatishlar bilan
YIM Yakuniy Baholash   → ikki oydan keyin, kamdan-kam bozorni harakatlantiradi
```

### Talqin

```
YIM > yillik 3% → kuchli o'sish → investorlarni jalb qiladi → valyuta kuchayadi
YIM 1–2% → o'rtacha o'sish → neytral
YIM ard. 2 chorak < 0% → texnik retsessiya → valyuta zaiflashadi
```

## 9. Xarid qobiliyati pariteti (PPP)

PPP: uzoq muddatda **valyuta kurslari turli mamlakatlarda bir xil tovarlar narxini tenglashtiruvi** kerak.

### Big Mac indeksi (The Economist)

Hazilomuz, ammo ishlaydi:
```
AQShda Big Mac: $5,69
Buyuk Britaniyada Big Mac: £4,29 (~$5,41)
Xulosa: GBP PPP ga nisbatan biroz past baholangan
```

!!! warning "PPP — uzoq muddatli vosita"
    PPP 3–10 yillik harakatlarni tushuntiradi, lekin haftalik savdo uchun **foydasiz**.
    Stavkalar kapital oqimini qo'llab-quvvatlaguncha valyuta PPP bo'yicha «yuqori baholangan»
    bo'lib yillarca qolishi mumkin.

## 10. Fundamentalni texnik bilan birlashtirish

Eng yaxshi shart — **ikki tahlil ham rozi** bo'lganda:

```
Fundamental deydi: USD ko'tarilishi kerak (Fed hawk, CPI yuqori)
Texnik deydi: EUR/USD asosiy qarshilikda, RSI haddan tashqari sotib olingan
→ Qarshilik darajasidan EUR/USD SELL izlaymiz
→ Fundamental «yelkama-yelka shamol» beradi, texnik kirish nuqtasini beradi
```

### Fundamental uchun vaqt oralig'i

| Gorizontal | Vosita |
|---|---|
| Uzoq muddatli (oylar) | Stavkalar, YIM, MB sikli |
| O'rta muddatli (haftalar) | CPI, NFP, PMI |
| Qisqa muddatli (kunlar/soatlar) | MB nutqlari, alohida ma'lumotlar |
| Ultra-qisqa (daqiqalar) | Texnik tahlil |

!!! tip "«Shamolga qarshi savdo qilma» qoidasi"
    Agar fundamental «USD shu chorakda ko'tarilmoqda» desa, **uzoq muddatli EUR/USD longlar izlama**.
    Qisqa muddatli tuzatishlarni savdo qilish mumkin, lekin asosiy trend sizga qarshi.
