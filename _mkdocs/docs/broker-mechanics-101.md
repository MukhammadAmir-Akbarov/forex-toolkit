# ⚙️ Реальная механика брокера — что происходит «за кулисами»

!!! abstract "Зачем это знать"
    Большинство новичков думает: «Купил EUR/USD — рынок отреагировал». На самом деле твой
    ордер может никогда не попасть «на рынок» — брокер берёт другую сторону сделки сам.
    Понимание этого объясняет **проскальзывание, реквоты, дифференциацию спреда** и
    помогает выбрать брокера не по яркой рекламе, а по реальным условиям.

> **Учебный материал.** Описанные механизмы — общеизвестные факты индустрии, не
> утверждения о конкретных брокерах.

## 1. Две модели исполнения: MM vs ECN/STP

### Market Maker (MM) — «Кухня»

Брокер **сам берёт противоположную сторону** твоей сделки. Ты купил EUR/USD — брокер продал.

```
Тебе: Buy 0.1 lot EUR/USD по 1.08463
Брокер внутри: «принял» продажу 0.1 lot

Варианты, что делает брокер с этим риском:
A) Хеджирует у поставщика ликвидности (честный MM)
B) Не хеджирует и «надеется», что ты проиграешь (конфликт интересов)
```

**Признаки MM-брокера:**
- Фиксированный спред (2–3 pip на EUR/USD даже ночью)
- Реквоты при быстром рынке
- Минимальный депозит $10–50
- «Instant Execution»

### ECN (Electronic Communication Network)

Твой ордер **реально выходит на рынок** — в пул ликвидности от банков, других брокеров,
институциональных игроков.

```
Тебе: Buy 0.1 lot EUR/USD
Брокер: отправляет на ECN-площадку
ECN: находит продавца (другой трейдер, банк, LP)
Исполнение: по лучшей доступной цене
```

**Признаки ECN-брокера:**
- Плавающий спред (от 0,0 pip + комиссия $3–5 за лот)
- Нет реквотов (Market Execution всегда)
- Минимальный депозит $200–1000
- Прозрачное ценообразование

### STP (Straight Through Processing)

Гибрид: ордера проходят автоматически к поставщику ликвидности, но брокер может добавить
**markup к спреду** вместо комиссии.

| Критерий | Market Maker | ECN/STP |
|---|---|---|
| Исполнение | Instant / Requote | Market (без реквотов) |
| Спред | Фиксированный, шире | Плавающий, уже + комиссия |
| Конфликт интересов | Возможен | Минимальный |
| Минимальный депозит | Низкий ($10–100) | Выше ($200+) |
| Подходит для | Обучение, мелкие счета | Активная торговля |

## 2. Проскальзывание: откуда и почему

**Slippage** — разница между ценой в момент отправки ордера и ценой исполнения.

### Причины:

1. **Скорость**: рынок движется быстрее, чем летит твой ордер (10–100 мс)
2. **Ликвидность**: при большом объёме не хватает контрагентов по одной цене
3. **Волатильность**: во время новостей цена прыгает на тики за миллисекунды

```
Пример позитивного проскальзывания (в твою пользу):
Отправил Buy Market по 1.08463
Исполнено по 1.08459 → на 0.4 pip лучше
(В ECN такое бывает при движении цены В ТВОЮ пользу пока ордер летел)

Пример негативного проскальзывания (в убыток):
Отправил Buy Market по 1.08463
Исполнено по 1.08481 → на 1.8 pip хуже
(Цена прыгнула пока ордер проходил)
```

### Как минимизировать проскальзывание:

- Торгуй **в ликвидное время** (Лондон/Нью-Йорк, не азиатская сессия)
- Используй **Limit вместо Market** — гарантирует цену, но не гарантирует исполнение
- Избегай **Market в момент выхода новостей**
- Проверяй **среднее проскальзывание** брокера в его отчётах о качестве исполнения

## 3. Реквоты — что это и как избежать

**Requote** — брокер отклоняет твою цену и предлагает другую.

```
Нажимаешь «Buy» по 1.08463
Всплывает окно: «Цена изменилась. Новая цена: 1.08471. Принять?»
```

Это типично для **Instant Execution** у MM-брокеров. При Market Execution реквотов нет —
ордер всегда исполняется, но по рыночной цене.

### Как избежать реквотов:

1. Выбирай брокера с **Market Execution**
2. Не торгуй **Market в моменты выхода новостей**
3. Проверяй статистику: брокер обязан публиковать процент реквотов

## 4. Спред: фиксированный vs плавающий

**Спред** — разница между Ask (покупка) и Bid (продажа). Это главный «налог» трейдера.

```
EUR/USD: Bid = 1.08450, Ask = 1.08453
Спред = 0.3 pip (или $0,30 за 0.1 лот)
```

### Когда спред расширяется:

| Время / событие | Спред EUR/USD |
|---|---|
| Лондон+Нью-Йорк перекрытие (15:00–17:00 UTC) | 0,1–0,5 pip |
| Азиатская сессия | 0,5–1,5 pip |
| За 5 мин до/после 🔴 новости | 3–50+ pip |
| В пятницу вечером / выходные | 2–5 pip |
| Открытие недели (Sunday 22:00 UTC) | 5–15 pip |

### Реальная стоимость спреда

```
Стратегия: 10 сделок в день, 0.1 лот EUR/USD, спред = 0.5 pip
Стоимость спреда за 1 сделку = 0.5 pip × $1 = $0.50
За день = $0.50 × 10 = $5.00
За месяц (22 дня) = $110.00
```

Это **выход из безубытка на каждой сделке** — цена должна пройти хотя бы спред, чтобы
вернуться в ноль.

## 5. Своп — стоимость удержания позиции ночью

**Swap (Rollover)** — плата или начисление за **удержание позиции через полночь (22:00 UTC)**.

Логика: ты держишь одну валюту и «занял» другую. Разница в процентных ставках этих валют —
и есть своп.

```
Long EUR/USD (держишь EUR, занял USD):
Ставка EUR = 4,0%, Ставка USD = 5,5%
Ты получаешь 4,0%, платишь 5,5%
Своп = отрицательный (ты платишь)

Short EUR/USD (держишь USD, занял EUR):
Ты получаешь 5,5%, платишь 4,0%
Своп = положительный (тебе начисляют)
```

### Тройной своп в среду

На forex-рынке **расчёт идёт на T+2 (два рабочих дня)**. Позиция, удержанная через среду 22:00,
несёт своп за три дня (ср + сб + вс). Это особенно важно при скальпинге.

!!! warning "Своп на экзотических парах"
    На парах USD/TRY, USD/ZAR, USD/BRL свопы могут достигать **−$10–30 за лот в день**
    для лонга. При удержании 10+ дней это значительный убыток даже без движения цены.

### Swap-free счета (исламские)

Брокеры предлагают **swap-free** счета (без свопа) для мусульман. Но обычно заменяют своп
на **административную комиссию** при удержании > 3 дней. Проверяй реальные условия.

## 6. Маржа и маржин-колл: механика

**Маржа** — залог, который блокирует брокер при открытии позиции.

```
Счёт: $1000, плечо 1:100, открываешь 0.1 lot EUR/USD
Стоимость позиции = 10 000 EUR ≈ $10 800
Маржа = $10 800 / 100 = $108 → брокер блокирует $108 из $1000
Свободная маржа = $1000 − $108 = $892
```

### Margin Call vs Stop Out

| Уровень | Что происходит |
|---|---|
| **Margin Call** (~100% уровня маржи) | Брокер предупреждает: пополни счёт |
| **Stop Out** (~50% уровня маржи) | Брокер принудительно закрывает позиции |

```
Пример Stop Out:
Маржа = $108, Stop Out на 50%
Триггер Stop Out = $108 × 50% = $54 equity
Если убыток по позиции = $946 (от $1000 осталось $54)
→ Брокер закрывает позицию принудительно
```

!!! danger "Никогда не открывай позицию, которая занимает >10% от счёта в марже"
    Правило: маржа одной позиции ≤ 2–5% от депозита. Иначе пара экстремальных движений
    → Stop Out.

## 7. Реальный конфликт интересов

### «B-книга» vs «A-книга»

У каждого брокера есть внутреннее деление клиентов:

**A-книга** — прибыльные, опытные трейдеры. Их ордера выводятся на реальный рынок.
Брокер зарабатывает на комиссии/спреде.

**B-книга** — большинство розничных трейдеров. Их ордера **не выводятся** — брокер
«принимает» сделку на себя. Когда ты теряешь → брокер зарабатывает.

```
Статистика: 70–80% розничных трейдеров теряют деньги.
Для MM-брокера с B-книгой это означает:
Прибыль брокера ≈ убытки клиентов (без выхода на рынок)
```

!!! warning "Это не значит, что MM-брокер «жульничает»"
    Регулируемый MM-брокер не может произвольно двигать цены — они показывают
    котировки поставщиков ликвидности. Конфликт — в **мотивации**: MM выгодно,
    чтобы ты терял. ECN безразличен к твоему результату (зарабатывает на объёме).

### Как отличить честного брокера

1. **Регуляция** — FCA (Великобритания), ASIC (Австралия), CySEC (Кипр), ЦБ РФ/РК.
   Нет лицензии = офшор = риск полной потери.
2. **Отчёты о качестве исполнения** — FCA требует раскрывать статистику проскальзывания.
3. **Сегрегация счетов** — деньги клиентов хранятся отдельно от средств брокера.
4. **Независимые отзывы** — Trustpilot, WikiFX, форумы трейдеров.

## 8. Как выбрать брокера по объективным критериям

| Критерий | Красный флаг | Хороший знак |
|---|---|---|
| Регуляция | Нет / офшор Вануату/Белиз | FCA, ASIC, CySEC, FSA |
| Спред EUR/USD | > 2 pip в рабочее время | < 0.5 pip (ECN) или < 1 pip (MM) |
| Исполнение | Реквоты, принудительное расширение спреда | Market Execution, прозрачная статистика |
| Пополнение/вывод | Комиссия > 3%, задержка > 3 дней | 0% комиссия, вывод за 24 часа |
| Минимальный депозит | > $1000 без причины | $100–500 для стандарт |
| Обучение/поддержка | Агрессивные «менеджеры», звонки | Нейтральная поддержка |
| Бонусы | «Бонус 100% на депозит» (часто не выводится) | Без бонусов или прозрачные условия |
