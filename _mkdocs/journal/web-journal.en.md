# 📊 Web Trading Journal

!!! abstract "What this tool does"
    Upload a CSV journal or MT5 HTML report and the browser will calculate Win Rate, Profit Factor,
    P&L, total R, maximum drawdown, and discipline. Filter trades by date, pair,
    direction, and rule compliance.

    Plans from the Pre-trade screen appear here automatically. Move them through
    **Plan → Open → Closed**, complete the post-trade review, and send the
    resulting statistics to a personal Monte Carlo model.

!!! tip "Privacy"
    The file is processed **only in your browser**. It is not uploaded and is
    stored locally so the journal can be restored next time.

Both project formats are supported: the extended
[`trading-journal-template.csv`](https://github.com/MukhammadAmir-Akbarov/forex-toolkit/blob/main/journal/trading-journal-template.csv)
and the compact CSV generated by `forex-journal`, plus MT5 HTML reports.

To export one: **MT5 → View → Toolbox → History → right-click → Report →
HTML**. Review the report for any details you do not want to share; the tool
still processes the file locally only.

The same import is available from the terminal:

```bash
forex-journal import-mt5 report.html --out journal/mt5-trades.csv
```

## Reading the results

- **Win Rate** uses Win/Loss trades only, so break-even does not distort it.
- **Profit Factor** = gross profit / gross loss.
- **Total R** uses `result_r`; if absent, it calculates `result_usd / risk_usd`.
- **Maximum drawdown** is the deepest equity decline from a previous peak.
- **Rules followed** is the share of `yes` among trades where the field is present.

Collect at least **30 trades using one strategy** before drawing firm conclusions.
