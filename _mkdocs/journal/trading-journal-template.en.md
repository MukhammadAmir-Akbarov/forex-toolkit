## Trade №1 — example

### Context
- **Date / time:** 2026-05-13, 14:30 (UTC+5)
- **Pair:** EUR/USD
- **Timeframe:** H1 (analysis), H4 (trend)
- **Setup:** Pullback to EMA50 + bullish engulfing
- **Direction:** Long

### Pre-trade analysis
- **H4 trend:** uptrend, price above EMA200 ✓
- **H1 structure:** higher highs, higher lows ✓
- **Signal:** 14:00 candle — bullish engulfing right on EMA50 ✓
- **RSI(14):** 52 (neutral, not at extremes) ✓
- **News:** no high-impact releases in the next 2 hours ✓
- **Checklist:** all 5 ☑

| **Outcome** | **WIN** |

### Review

## Trade №2 — example (planned loss)

### Context
- **Date / time:** 2026-05-13, 18:20
- **Pair:** GBP/USD
- **Timeframe:** H1 / H4
- **Setup:** Pin bar at H4 resistance
- **Direction:** Short

### Parameters
| | |
|---|---|
| Entry | 1.2655 |
| SL | 1.2680 (+25 pips) |
| TP | 1.2605 (−50 pips) |
| R:R | 1:2 |
| Lot | 0.02 |
| Risk | $5.00 |

### Result
| | |
|---|---|
| Close | 1.2680 (stop hit) |
| Time | 20:10 |
| Result | −25 pips, −$5.00, −1R |
| **Outcome** | **LOSS** |

### Review
- **Followed the rules?** Yes
- **Emotions:** disappointment, but no tilt
- **What I did well:** correctly identified the setup, did not move the stop
- **Mistakes:** none — a clean planned loss
- **Takeaway:** planned losses are a normal part of the statistics. With R:R 1:2 and a 40% win rate you are still profitable. **Do not revenge-trade** — the next trade only on a valid signal.
