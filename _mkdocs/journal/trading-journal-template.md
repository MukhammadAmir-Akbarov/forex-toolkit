## Сделка №1 — пример

### Контекст
- **Дата / время:** 2026-05-13, 14:30 (UTC+5)
- **Пара:** EUR/USD
- **Таймфрейм:** H1 (анализ), H4 (тренд)
- **Сетап:** Откат к EMA50 + бычье поглощение
- **Направление:** Long

### Анализ перед сделкой
- **H4 тренд:** восходящий, цена выше EMA200 ✓
- **H1 структура:** higher highs, higher lows ✓
- **Сигнал:** свеча 14:00 — бычье поглощение прямо на EMA50 ✓
- **RSI(14):** 52 (нейтрально, не в крайностях) ✓
- **Новости:** в ближайшие 2 часа красных нет ✓
- **Чек-лист:** все 5 ☑

### Параметры сделки
| Параметр | Значение |
|---|---|
| Цена входа | 1.0852 |
| Stop Loss | 1.0827 (−25 пипсов) |
| Take Profit | 1.0902 (+50 пипсов) |
| R:R | 1:2 |
| Размер позиции | 0.02 лота |
| Риск ($) | $5.00 (0.5% от $1000) |

### Результат
| | |
|---|---|
| Цена закрытия | 1.0902 |
| Время закрытия | 16:45 |
| Итог в пипсах | +50 |
| Итог в $ | +$10.00 |
| R-итог | +2R |
| **Исход** | **WIN** |

### Ревью
- **Следовал правилам?** Да (все 5 пунктов чек-листа)
- **Эмоции до:** спокойствие
- **Эмоции в сделке:** небольшое волнение при откате на −10 пипсов, не двигал стоп
- **Эмоции после:** удовлетворение
- **Что сделал хорошо:** дождался закрытия сигнальной свечи, не вошёл на её формировании
- **Ошибки:** нет
- **Вывод:** дисциплина + терпение = плановая прибыль. Повторять.

## Сделка №2 — пример (убыток по плану)

### Контекст
- **Дата / время:** 2026-05-13, 18:20
- **Пара:** GBP/USD
- **Таймфрейм:** H1 / H4
- **Сетап:** Пин-бар у сопротивления H4
- **Направление:** Short

### Параметры
| | |
|---|---|
| Вход | 1.2655 |
| SL | 1.2680 (+25 пипсов) |
| TP | 1.2605 (−50 пипсов) |
| R:R | 1:2 |
| Лот | 0.02 |
| Риск | $5.00 |

### Результат
| | |
|---|---|
| Закрытие | 1.2680 (стоп) |
| Время | 20:10 |
| Итог | −25 пипсов, −$5.00, −1R |
| **Исход** | **LOSS** |

### Ревью
- **Следовал правилам?** Да
- **Эмоции:** разочарование, но без тильта
- **Что сделал хорошо:** правильно распознал сетап, стоп не двигал
- **Ошибки:** нет — чистый убыток по плану
- **Вывод:** убытки по плану — нормальная часть статистики. При R:R 1:2 и win rate 40% всё ещё в плюсе. **Не лезть отыгрываться** — следующая сделка только по сигналу.
