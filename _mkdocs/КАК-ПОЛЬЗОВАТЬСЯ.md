# Как пользоваться этим проектом — экскурсия

> Прочитай этот файл **первым**. Здесь объясняется простым языком, что у тебя есть, зачем оно нужно, и в каком порядке всё использовать.

---

## 1. Что вообще лежит в этой папке?

У тебя есть **3 типа материалов**:

| Тип | Что это | Где лежит |
|---|---|---|
| 📚 **Книги** (учебные тексты) | Объясняют теорию forex | `*.md` файлы в корне и в `docs/` |
| 📝 **Шаблоны** | Готовые формы для ведения журнала | `journal/` |
| 🛠️ **Программы** (Python) | Инструменты, которые что-то считают | `tools/`, `bot/` |

Можно использовать **только тексты** (без Python вообще) — этого хватит, чтобы научиться торговать. Python — это бонус для тех, кто хочет автоматизировать расчёты и понимать рынок глубже.

## 3. Дорога новичка — что делать в каком порядке

### 🟢 Неделя 1: Читаем теорию

**Шаг 1.** Открой [forex-guide.md](forex-guide.md) — это твой главный учебник.

Внутри 14 разделов: что такое forex, как читать котировки, как работают сделки, как выбрать брокера, риск-менеджмент, типичные ошибки, дорожная карта на полгода. Около 700 строк, читается за 2–3 часа. **Прочитай дважды.**

**Шаг 2.** Открой [docs/technical-analysis.md](docs/technical-analysis.md) — расширенный гайд по «как читать график».

Здесь **12 цветных графиков**: что такое свеча, паттерны разворота, тренды, индикаторы (EMA, RSI, MACD, Bollinger Bands), графические паттерны (голова и плечи, треугольники). Это самый «визуальный» документ — рассматривай графики, не только читай.

**Шаг 3.** Открой [docs/strategy-details.md](docs/strategy-details.md) — детальный разбор одной торговой стратегии.

Это первая конкретная **стратегия** для тебя. Она называется «Откат к EMA50 по тренду». Описана от и до: когда заходить, где ставить стоп, где брать прибыль, когда стратегия НЕ работает.

---

### 🟡 Неделя 2: Готовим инфраструктуру

**Шаг 4.** Зарегистрируйся у регулируемого брокера (см. раздел 4 в главном гайде). Открой **только демо-счёт**.

**Шаг 5.** Установи MetaTrader 5 (бесплатный) с сайта брокера. Подключись к демо-счёту.

**Шаг 6.** Открой [journal/](journal/) — выбери, где будешь вести журнал сделок:

- **Google Sheets** (рекомендую новичку): импортируй `trading-journal-template.csv`. Инструкция в [journal/README.md](journal/README.md).
- **Obsidian / Notion / Markdown**: скопируй `trading-journal-template.md`.

Журнал — самый важный инструмент роста. Без него ты не научишься.

---

### 🟠 Недели 3–12: Торгуем на демо

**Шаг 7.** Перед **каждой** сделкой запускай калькулятор позиции:

```bash
.venv/bin/python tools/position_calculator.py
```

Он спросит:
- Депозит (например, 1000)
- Риск % (0.5)
- Стоп в пипсах (25)
- Пара (EURUSD)

И скажет, **сколько лотов** ставить в терминале. Без этого ты будешь брать «на глаз» — самая частая ошибка новичков.

**Шаг 8.** После **каждой** сделки записывай её в журнал. Минимум: дата, пара, направление, вход, стоп, тейк, итог, следовал правилам? (да/нет), вывод.

**Шаг 9.** Раз в неделю — еженедельный отчёт по журналу (шаблон есть внутри файла журнала).

**Шаг 10.** Раз в месяц — анализ: какие сделки были по правилам? Где ты ошибаешься?

### 🔵 Когда станет интересно — бэктест

Это **необязательно**, но очень полезно для понимания. Запусти:

```bash
.venv/bin/python bot/backtest.py
```

Программа:
1. Сгенерирует 2000 синтетических свечей
2. Применит стратегию из `strategy-details.md` автоматически
3. Покажет статистику: win rate, profit factor, итоговый результат
4. Нарисует **equity curve** (график твоего баланса по сделкам) в `bot/equity-curve.png`

Это даст тебе представление, **как стратегия себя ведёт на длинной дистанции**, без необходимости вручную проверять 100 сделок.

## 4. Как открыть Markdown-файлы (это `.md`)

Markdown — это формат текста с разметкой. Открыть можно **по-разному**:

### Вариант 1: VSCode (рекомендую)
1. Открой папку `trading/` в VSCode (File → Open Folder)
2. Кликни на любой `.md` файл слева
3. **Ctrl+Shift+V** (или **Cmd+Shift+V** на Mac) — откроет красивый preview

В preview ты увидишь:
- Цветные заголовки
- Кликабельные ссылки
- Картинки прямо в тексте
- Таблицы

### Вариант 2: GitHub / Obsidian
Если запушить папку на GitHub — все `.md` отрисуются красиво автоматически.

Obsidian / Notion — отличные приложения для ведения такой базы знаний.

### Вариант 3: Любой текстовый редактор
Открыть можно даже Блокнотом, но будет некрасиво (без форматирования).

## 5. Как пользоваться Python-скриптами

> Если ты никогда не писал Python — не пугайся. Тебе не нужно ничего знать. Просто запускай команды.

### Шаг 1: Открой терминал

- **macOS:** Cmd+Space → «Terminal» → Enter
- **Windows:** Win+R → «cmd» → Enter
- **VSCode:** Terminal → New Terminal

### Шаг 2: Перейди в папку проекта

```bash
cd /Users/mukhammadamir/Sites/WORK/trading
```

### Шаг 3: Запускай команды

Любой Python-скрипт запускается так:

```bash
.venv/bin/python <путь-к-скрипту>
```

**Примеры:**

```bash
# Калькулятор позиции (задаст вопросы)
.venv/bin/python tools/position_calculator.py

# Калькулятор однострочно (без вопросов)
.venv/bin/python tools/position_calculator.py --balance 1000 --risk 0.5 --stop 25 --pair EURUSD

# Бэктест стратегии
.venv/bin/python bot/backtest.py

# Перегенерация всех графиков для учебников (обычно не нужно)
.venv/bin/python tools/chart_generator.py
```

### Что такое `.venv/`?

Это **виртуальное окружение Python** — изолированная коробочка, в которой установлены библиотеки `matplotlib`, `numpy`, `pandas`. Я её создал заранее, чтобы тебе не пришлось ничего устанавливать.

**Не удаляй `.venv/`**, иначе скрипты перестанут работать. Если случайно удалил — пересоздай:

```bash
python3 -m venv .venv
.venv/bin/pip install matplotlib numpy pandas
```

## 6. Что показывает каждый скрипт — на примерах

### tools/position_calculator.py — калькулятор позиции

**Зачем:** считает, сколько лотов ставить в сделке, чтобы не потерять больше X% депозита.

**Пример запуска:**

```bash
.venv/bin/python tools/position_calculator.py --balance 1000 --risk 0.5 --stop 25 --pair EURUSD
```

**Что увидишь:**

```
╭─────────────────────────────────────────╮
│  КАЛЬКУЛЯТОР РАЗМЕРА ПОЗИЦИИ            │
╰─────────────────────────────────────────╯

Входные данные:
  Депозит:           $1,000.00
  Риск:              0.50% = $5.00
  Стоп-лосс:         25 пипсов
  Пара:              EURUSD
  Стоимость пипса:   $10.00 за 1 лот

Расчёт:
  Размер (точный):   0.0200 лота
  Размер (округл.):  0.02 лота
  Реальный риск:     $5.00 (0.50%)

→ Выстави в терминале: 0.02 лота
```

**Как читать:** «Выстави в терминале: 0.02 лота» — это число, которое ты вводишь в MetaTrader при открытии сделки.

---

### bot/backtest.py — бэктестер стратегии

**Зачем:** прогоняет стратегию на исторических данных и говорит, **была бы она прибыльной**.

**Пример запуска:**

```bash
.venv/bin/python bot/backtest.py
```

**Что увидишь:**

```
Генерирую 2000 синтетических H1-свечей…
Период: 2026-01-01 → 2026-03-25 (2000 свечей)
Сканирую сигналы…
  Найдено сигналов: 11
Прогоняю сделки…
  Реальных входов (без перекрытий): 9

╭──────────────────────────────────────────────────╮
│  РЕЗУЛЬТАТЫ БЭКТЕСТА                            │
╰──────────────────────────────────────────────────╯

  Всего сделок:         9
  Прибыльных (win):     5
  Убыточных (loss):     4
  Win rate:             55.6%
  Profit Factor:        2.50
  Expectancy:           +0.67R / сделку
  Итого:                +6.00R

  ✅ Profit Factor ≥ 1.5 — статистика подходящая.

  График сохранён: bot/equity-curve.png
```

**Как читать:**

- **Win rate 55.6%** — больше половины сделок были прибыльными.
- **Profit Factor 2.50** — на каждый $1 убытка пришлось $2.50 прибыли. Хорошо (норма ≥ 1.5).
- **Expectancy +0.67R** — *в среднем* одна сделка приносит 0.67 от того, чем ты рисковал. На 100 сделках = +67R.
- **Итого +6.00R** — суммарный результат: +6 раз величина одного риска.

Что такое **R**? Это **единица твоего риска**. Если ты рискнул $5 — это «1R». Прибыль в $10 = «+2R». Удобно мерить результаты независимо от того, какого размера твой депозит.

**Картинка** `bot/equity-curve.png` показывает, как рос/падал твой условный баланс от сделки к сделке.

## 7. Что делать в первый день — конкретный план

Если ты прямо сейчас сел за компьютер:

1. **0:00** — открыл VSCode, открыл папку `trading/`
2. **0:05** — открыл [forex-guide.md](forex-guide.md), включил preview (Cmd+Shift+V)
3. **0:10** — начал читать. **Прочитай разделы 1–7** (это самое важное: что такое forex, термины, риск-менеджмент). На это ~1.5 часа.
4. **1:30** — сделай **перерыв 30 мин**. Не пытайся прочитать всё за раз.
5. **2:00** — продолжай с разделов 8–14. Ещё ~1 час.
6. **3:00** — открой [docs/technical-analysis.md](docs/technical-analysis.md). Не нужно понимать всё с первого раза — **изучай картинки**, читай подписи.
7. **4:00** — посмотри [docs/strategy-details.md](docs/strategy-details.md), пока без углубления.
8. **4:30** — запусти калькулятор позиции один раз — просто чтобы понять, как он работает:
   ```bash
   .venv/bin/python tools/position_calculator.py
   ```
9. **5:00** — закрой компьютер. **Завтра** перечитай главный гайд, потом начинай выбирать брокера.

**Не торопись.** Лучше потратить неделю на чтение, чем две недели исправлять ошибки от поспешного входа на реал.

## 8. Чего НЕ делать

- ❌ **Не открывай реальный счёт сразу** после прочтения. Минимум 2–3 месяца демо.
- ❌ **Не запускай `backtest.py` и не считай, что это «бот, который торгует за тебя»**. Это симулятор истории, а не живой автотрейдер.
- ❌ **Не редактируй `.venv/`** — это служебная папка.
- ❌ **Не пушь папку `journal/` с реальными сделками публично** на GitHub (там твоя личная статистика). `.gitignore` уже настроен на защиту, но проверь.
- ❌ **Не верь обещаниям лёгких денег** — ни от блогеров, ни от каналов, ни от «гуру».

## 9. Если что-то не работает

### Скрипт не запускается — «command not found»
Проверь, что ты находишься в папке `trading/`:

```bash
pwd
# должно показать: /Users/mukhammadamir/Sites/WORK/trading
```

Если нет — `cd /Users/mukhammadamir/Sites/WORK/trading`.

### Скрипт пишет «No module named 'matplotlib'»
Запускай через `.venv/bin/python`, а не просто `python` или `python3`:

```bash
# ❌ Так не работает:
python tools/position_calculator.py

# ✅ Так работает:
.venv/bin/python tools/position_calculator.py
```

### Картинки в Markdown не отображаются
Открывай Markdown через **VSCode preview** (Cmd+Shift+V) или загрузи папку на GitHub.

### Скрипт `position_calculator.py` пишет «нет такой пары»
Поддерживаются мажоры. Список:

```bash
.venv/bin/python tools/position_calculator.py --list-pairs
```
