# Приватность

Сайт работает без регистрации. Учебный прогресс, ответы, журнал и торговые
черновики хранятся только в локальном хранилище браузера.

## Анонимная статистика

GoatCounter получает просмотр страницы и только названия завершённых действий:
расчёт, Replay, импорт журнала, экзамен, переход из кабинета и оценка полезности.
Суммы, валютные пары, параметры расчёта и содержимое журнала не отправляются.

Счётчик не использует рекламные cookie. Его можно полностью заблокировать
настройками браузера или блокировщиком. Без аналитики все функции продолжают
работать.

## Внешние сервисы

Некоторые страницы дают ссылки на внешние источники. Курс валют при ручном вводе
никуда не передаётся. При включении комментариев giscus действует политика
GitHub; сейчас комментарии требуют отдельного включения владельцем проекта.

Очистить локальные данные можно через настройки сайта в браузере.
