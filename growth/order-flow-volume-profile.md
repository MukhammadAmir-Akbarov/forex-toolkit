# Order Flow и Volume Profile — продвинутый теханализ

> Это уровень **«после базы»**. Сначала освой свечи, EMA, RSI и базовую стратегию. Этот раздел открывай через **6+ месяцев** практики, когда захочешь глубже понять, что происходит в стакане.

## Зачем это нужно

Классический ТА (свечи, индикаторы) — это **что произошло с ценой**.
Order Flow / Volume Profile — это **кто торговал и в каких объёмах**.

Профессиональные трейдеры **смотрят на объёмы**, потому что цена без объёма — иллюзия. Прорыв уровня без объёма часто ложный, прорыв с большим объёмом — настоящий.

## 1. Концепции

### 1.1 Order Book (стакан)

В реальном времени биржа показывает **bid/ask по уровням цен**:

```
                ASK (продавцы)
   1.0855  ┃ 2 500 000 лотов
   1.0854  ┃ 1 800 000 лотов
   1.0853  ┃   500 000 лотов
─── текущая цена ────
   1.0852  ┃   400 000 лотов
   1.0851  ┃ 1 200 000 лотов
   1.0850  ┃ 3 000 000 лотов
                BID (покупатели)
```

- **Большая стена покупателей** ниже текущей цены → поддержка
- **Большая стена продавцов** выше → сопротивление
- **Тонкая ликвидность** → цена быстро пройдёт уровень

⚠️ **Важно:** В forex стакан **не доступен** для розничных трейдеров (это OTC-рынок). В отличие от криптобирж и фондового рынка.

### 1.2 Volume Profile (профиль объёма)

Vertical histogram на правой стороне графика, показывает **сколько объёма прошло на каждом уровне цены** за период:

```
Цена │
1.090 ┃▓▓
1.088 ┃▓▓▓▓▓
1.086 ┃▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ ← POC (Point of Control)
1.084 ┃▓▓▓▓▓▓▓▓▓▓
1.082 ┃▓▓▓
1.080 ┃▓
      └────────────
```

Ключевые термины:
- **POC (Point of Control)** — уровень с максимальным объёмом. Самая «честная» цена.
- **Value Area (VA)** — диапазон, где прошло 70% объёма
- **Value Area High (VAH)** — верх Value Area
- **Value Area Low (VAL)** — низ Value Area
- **HVN (High Volume Node)** — зона с высоким объёмом — поддержка/сопротивление
- **LVN (Low Volume Node)** — зона с низким объёмом — цена пробегает быстро

### 1.3 ICT концепции (Inner Circle Trader)

Популярная методология (Майкл Хаддлстон). Ключевые понятия:

- **Liquidity** — где стоят стопы массы трейдеров (выше swing high / ниже swing low)
- **Liquidity sweep** — рынок забирает эти стопы перед разворотом
- **Order Block** — последняя свеча перед сильным импульсом, часто работает как поддержка/сопротивление
- **Fair Value Gap (FVG)** — разрыв между свечами, который рынок часто заполняет
- **Smart Money Concept (SMC)** — теория, что крупные игроки манипулируют ценой

⚠️ **ICT — противоречивая школа.** Многие критикуют как «слишком сложное объяснение простых вещей». Изучай критически.

## 2. Где получить Volume в forex

Поскольку forex децентрализован, **истинного объёма нет**. Используют прокси:

### 2.1 Tick Volume

Каждое изменение цены = 1 тик. Тик-объём = количество тиков за свечу. Это **косвенный** показатель активности.

В MT5: правая кнопка по графику → **Volumes** → **Tick Volume**.

### 2.2 Futures Volume (точнее)

Реальный объём с **фьючерсного рынка** (CME):
- **6E** — фьючерс на EUR/USD
- **6B** — на GBP/USD
- **6J** — на JPY

Можно скачать через CME data (платно) или через TradingView (Pro подписка).

### 2.3 Aggregator данных

Сервисы, агрегирующие объёмы от нескольких брокеров:
- **Volfix** (платно)
- **ATAS** (платно, для проп-трейдеров)
- **Sierra Chart** (платно, более доступно)

Для большинства розничных трейдеров — **достаточно tick volume**.

## 3. Простые стратегии с Volume Profile

### 3.1 POC Magnet

**Идея:** Цена «магнетит» к POC предыдущего дня/недели.

```
Действия:
1. Постройте Volume Profile за вчерашний день (D1)
2. Найдите POC
3. Если сегодня цена далеко от POC — ждать возврата
4. Вход у POC после теста + свечного паттерна
```

### 3.2 Value Area Rejection

**Идея:** Цена отбивается от VAH / VAL.

```
Действия:
1. Найдите VAH и VAL вчерашнего дня
2. Если цена подходит снизу к VAL и отскакивает → long
3. Если цена подходит сверху к VAH и отскакивает → short
4. Стоп за пределами VA
5. Цель — POC
```

### 3.3 LVN Breakout

**Идея:** Цена быстро пробегает зоны с низким объёмом.

```
Действия:
1. Найдите LVN (зоны с тонкими столбиками)
2. Если цена начала движение к LVN — она часто пройдёт его быстро
3. Вход в направлении движения, цель — следующий HVN
4. Стоп под последним свингом
```

## 4. Как добавить Volume Profile в MT5

В MT5 нет встроенного Volume Profile. Нужно:

### Вариант А: бесплатный индикатор
1. Скачать с mql5.com: «Volume Profile» (есть бесплатные версии)
2. Через MetaEditor: File → Open Data Folder → MQL5/Indicators
3. Положить .mq5 / .ex5 файл
4. В MT5: Refresh → перетащить на график

### Вариант Б: TradingView (рекомендую)
1. На TradingView: Indicators → Volume Profile Visible Range
2. Бесплатно для базовой версии
3. Намного более наглядно, чем в MT5

### Вариант В: ATAS / Sierra Chart
- Профессиональные платформы
- $50-200/мес
- Полный Order Flow + Volume Profile + Footprint

## 5. Footprint Charts (Order Flow Bars)

Это эволюция свечей: внутри каждой свечи показано, **сколько было покупок и продаж на каждом уровне**:

```
EUR/USD H1 — Footprint:

1.0855  10 × 50       (10 покупок, 50 продаж — медведи давят)
1.0854  120 × 80      (баланс)
1.0853  200 × 150     (быки немного впереди)
1.0852  50 × 300      (медведи давят)
```

Помогает увидеть **дисбаланс** покупателей и продавцов **внутри свечи**, а не только её результат.

Доступно: **ATAS, Sierra Chart, TradingView (Pro+)**.

## 9. Реалистичные ожидания

Order Flow и Volume Profile — это **инструменты**, не магия.

❌ Они НЕ дают:
- «Чёткие сигналы вход/выход»
- 90% точности
- Возможность торговать без стопов
- Прибыль на любом таймфрейме

✅ Они ДАЮТ:
- Лучшее понимание контекста рынка
- Идеи о ликвидности
- Дополнительный фильтр для классических сетапов
- Уверенность в принятии решений (после долгого изучения)

---

## 10. Шаги если хочешь начать

1. **Сегодня:** установи TradingView, добавь Volume Profile Visible Range на EUR/USD
2. **Неделя:** наблюдай — где POC, VAH, VAL каждый день. Запиши уровни.
3. **Месяц:** найди связь между этими уровнями и движениями цены
4. **3 месяца:** попробуй простую стратегию (например, POC Magnet) на демо
5. **6 месяцев:** если работает — встрой как **фильтр** в свою основную стратегию

**Не торопись внедрять.** Volume Profile должен **дополнять**, а не заменять то, что у тебя работает.
